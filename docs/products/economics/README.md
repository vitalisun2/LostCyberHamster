## Как пользоваться и обновлять

1. Перед исследованием экономики прочитать этот файл.
2. Проверить изменения после указанного commit: `git diff --name-only 087593fdb5480d9f145763871ec021f6a3674e40 -- LostCyberHamster/Assets LostCyberHamster/Packages`; новые файлы видны через `git status --short`.
3. Перепроверять затронутые разделы по ссылкам на владельцев поведения. Повторять весь аудит при изменении общего потока экономики.
4. После изменения экономики обновить здесь факты, расчёты, источники и дату проверки соответствующего раздела. Общую дату/commit менять после сверки всех разделов.
5. Решения брейншторма записывать в раздел «Решения брейншторма», цели — в `goals.md`, исследование каждого этапа — в отдельный `research/NN_topic.md`. Предложение, принятое решение и работающий код обозначать отдельно.
6. Во время свободного брейншторма отвечать кратко. Полноценный research проводить по отдельной просьбе пользователя; общие идеи сохранять с соответствующим статусом.
7. Документы пишутся для агентов: факты, детали, числа, формулы, ссылки, статус проверки. Повторные объяснения и оформление свести к минимуму.

| Кристаллы | Покупка открытых скинов | 0 | `PlayerData.Crystals` |

### Случайный бонус

| Результат | Вероятность | Количество |
|---|---:|---:|
| Монеты | 70% | 3 |
| Энергия | 25,5% | До +20, максимум 100 |
| Жизнь | 1,5% | До +1, максимум 3 |
| Кристалл | 3% | 1 |

Расчёт на одно событие: **2,1 монеты и 0,03 кристалла в среднем**. Это математическое ожидание, не обещанная награда отдельного забега. Спецрежим бота `UseNoEnergyBonuses` заменяет энергетический дроп монетами; таблица описывает обычный режим.

### Повторное получение

- Валюта за игровые действия и подбор сразу попадает в общий баланс. Победа для её начисления не требуется.
- Подобранный объект убирается; повторный callback того же активного экземпляра защищён.
- Новая попытка заново создаёт объекты и допускает повторный заработок. Признак «валюта уровня уже получена» в этом потоке отсутствует.
- Поражение и обычный рестарт сами по себе не откатывают заработанный баланс. Сохранение на диск происходит в точках из раздела 8.

## 3. Расходы, обмен и реклама

| Покупка | Цена | Результат |
|---|---:|---|
| Кристалл | 500 монет | +1 кристалл |
| Энергия | 50 монет | Заполнение до 100 |
| Ульта | 100 монет | Заполнение до 100; требуется выбранная способность |
| Forest, ID 4 | 20 кристаллов | Покупка ранее открытого скина |
| Cowboy, ID 5 | 25 кристаллов | Покупка ранее открытого скина |
| Summer, ID 6 | 20 кристаллов | Покупка ранее открытого скина |
| Открытие скина или способности | 1 очко развития | Следующий элемент выбранной линии |
| Возрождение | Завершённая реклама | 1 жизнь в исходной попытке |

Покупка скина и его экипировка — отдельные действия. Для нового игрока базовый скин, ID 0, уже куплен. Текущие траты кристаллов ограничены тремя платными скинами. В обследованных production-путях обратного обмена, покупки жизней за валюту и покупок за реальные деньги не найдено.

Пополнение в забеге доступно только при неполной шкале, достаточном общем балансе и активном управлении. Сначала расходуется неизрасходованная добыча текущей попытки, затем недостающее — из накоплений. Добыча уже включена в общий баланс, поэтому цена списывается один раз. HUD показывает оставшиеся монеты попытки; прогресс заданий по сбору монет не уменьшается. Цены 50/100 фиксированные; гипотеза 25/50 и варианты размещения цены рассматриваются в [расчёте Morning](research/17_run_refills_and_coin_income.md).

Рекламный сервис:

- Держит один активный запрос. Требует загруженный профиль, поддерживаемую SDK платформу и сеть либо заранее загруженный показ.
- Выдаёт награду после `COMPLETED` и успешной записи. Пропуск показа награды не даёт.
- Сохраняет ID запроса; повторный callback не выдаёт вторую награду.
- Возрождение связано с исходными сценой и попыткой. Выход или рестарт отменяет этот контекст.
- Суточный лимит, cooldown и лимит возрождений на попытку в прикладном коде не найдены. Фактическая доступность зависит от рекламного провайдера.
- Unity Ads инициализируется с **`testMode: true`**. Коммерческий показ этим исследованием не подтверждён.

## 4. XP и очки развития

| Источник XP | Награда | Защита повторного получения |
|---|---:|---|
| Tutorial Complete или Skip | 150 | Общий постоянный флаг однократной выдачи |
| Первая победа и улучшение best-звёзд | 25 за первую победу +2 за новую звезду | Стабильный ключ уровня и сохранённый best |
| Получение награды Daily | 5 | Один раз на экземпляр квеста |
| Получение награды Story | 60 / 20 / 0 | Первый Morning Primary / другой Story / цель уровня игрока |
| Подтверждённое улучшение личного weekly-рекорда | 5 / 0 | Первая durable-подтверждённая запись UTC-дня / последующие; общий локальный журнал досок |

- Каждые **240 XP** повышают уровень на 1. Пока остаются открытия/tiers каталога — **1 DP**; после фактического завершения развития — **50 монет**. Порог постоянный; остаток XP переносится.
- Решение требует загруженных каталогов скинов и способностей. Новое развитие возвращает последующие LevelUp к DP. Покупка уже открытого скина за кристаллы учитывается отдельно от расхода DP.
- Награда каждого нового повышения сохраняется с XP в `PendingLevelUpRewards`. LevelUp показывает сохранённые суммы DP/монет; ACK очищает только показанный диапазон. Прежние повышения без квитанций показывают исторический DP, без конвертации баланса.
- Очки копятся. Игрок выбирает линию: скины или способности. Внутри каждой открывается следующий закрытый элемент каталога.
- Линия скинов: Forest, Cowboy, Summer. После открытия требуется покупка за кристаллы.
- Линия способностей: Energy Shield, Electric Strike, Skateboard. Открытую способность можно сразу выбрать.
- Текущий каталог требует **6 очков** для всех открытий: **уровень 7, 1440 суммарных XP** с нового профиля.
- Открытые способности улучшаются I→II→III по 1 DP за шаг сразу после открытия, если есть свободный DP. Все открытия и улучшения: 12 DP, уровень 13, 2880 XP.
- Weekly сохраняет решение 0/5 XP до применения. Retry и rollback локального облачного payload используют тот же decision. Квота общая для owner/environment в локальном журнале; независимые устройства и доверенное серверное время этим решением не покрыты.
- Для поздней отправки weekly owner и серверная неделя известны до забега; иначе запись LocalOnly.
- Без дополнительных XP первое повышение после tutorial/Skip наступает после трёх разных побед при сумме 8–9 звёзд: 241–243 XP. При меньшем результате оно гарантировано после четырёх разных побед: минимум 258 XP. Предложение урока щита привязано к первому Level Up.
- Первый Morning завершается после пяти разных уровней; Claim его Story добавляет 60 XP. С tutorial/Skip и этим Claim получается 345–365 суммарных XP: минимум `150 +5×27 +60 =345`, максимум `150 +5×31 +60 =365`.
- До открытия Barcelona: 44 разные победы, минимум по 64 звезды в New York и Paris. С tutorial/Skip и первым Story Claim: `150 +44×25 +128×2 +60 =1566 XP`; при 132 звёздах — 1574 XP. Это 6 заработанных DP и уровень 7. Без этого Claim получается 1506–1514 XP, также 6 DP. Daily, weekly и остальные Story учитываются отдельно.

## 6. Квесты и ротация наград

### Daily

Три слота: простой, средний, сложный; разные механики. Каждый квест даёт **10 монет +5 XP**. После получения всех трёх наград доступно ещё **30 монет**. Полный свежий набор: **60 монет +15 XP**.

| Механика | Цели: простая / средняя / сложная |
|---|---|
| Перепрыгнуть препятствия | 5 / 10 / 20 |
| Напрыгнуть на препятствия | 3 / 5 / 10 |
| Завершить уровни | 1 / 2 / 3 |
| Пробежать по крышам транспорта | 3 / 5 / 8 |
| Прыгнуть с крыши на живое препятствие | 1 / 2 / 3 |
| Перепрыгнуть с крыши на крышу | 3 / 5 / 8 |

- Действия текущей попытки переходят в прогресс Daily после успешного завершения уровня.
- Для дневной цели завершения уровней подходят повторные победы на одном уровне.
- Набор обновляется по локальной дате устройства; граница — местная полночь. `UsedGenerationDates` защищает от повторной генерации уже использованной даты.
- Завершённые задания с незабранной наградой сохраняют свои слоты при ротации. Новые задания заполняют свободные слоты.
- Доступная общая награда старого набора переносится в очередь вместе с её размером.
- Награда квеста, XP и отметка получения записываются одной транзакцией. Общая награда тоже сохраняется транзакцией.

### Story

Два активных слота:

1. Последовательная цель прохождения частей суток.
2. Случайная цель мастерства или развития: пройти часть суток на 3 звезды, достичь следующего уровня игрока, купить и надеть открытый скин, выбрать открытую неактивную способность. Цель покупки скина выбирается среди ещё не купленных.

Награда: **300 монет**, XP — **60** у первого Morning Primary, **20** у других Story, **0** у целей уровня игрока. В целях прохождения и мастерства учитываются разные уровни. Полученные цели исключаются из повторной выдачи. Слот с забранной наградой заменяется при смене даты генерации; незавершённый либо незабранный квест восстанавливается. Поэтому два слота не образуют бесконечную цепочку новых наград в один день.

Цели прохождения и мастерства берут число уровней из `PartProgress.TotalLevels`. Для Morning это пять разных побед; мастерство требует по три звезды на всех пяти уровнях. Награда первого Morning становится доступной после пятого уровня; предложение урока щита появляется раньше при первом повышении игрока.

Источники: [контент квестов][quest-data], [генерация Daily][daily-generator], [ротация и общая награда][daily-service], [календарь][daily-scheduler], [генерация Story][story-generator], [буфер попытки и выдача][quests].

## 7. Ресурсы забега и способности

| Ресурс | Расход | Пополнение |
|---|---|---|
| Жизни, максимум 3 | 1 за получение урона | Pickup жизни или случайный бонус: до +1; рекламное возрождение: 1 жизнь |
| Энергия, максимум 100 | 10 за обычный, усиленный и оба прыжка с крыши | +1 за секунду обновления механики; энергетик/пицца: до +30; случайный бонус: до +20; покупка: до 100 |
| Заряд ульты, максимум 100 | Весь заряд после успешной активации | Разрушение препятствий при напрыгивании; покупка: до 100 |

В режиме скейтборда прыжки обходят расход энергии. Пополнение до максимума выдаёт только недостающий объём.

| Способность | Заряд за препятствие | Препятствий с нуля до 100 | Длительность в каталоге |
|---|---:|---:|---:|
| Energy Shield | 20 | 5 | I/II/III: 3/5/7 секунд |
| Electric Strike | 35 | 3 | 0; запуск удара |
| Skateboard | 20 | 5 | I/II/III: 5/7/10 секунд; 1/2/3 полные комбинации |

## 8. Владельцы состояния и сохранение

| Участок | Владелец и контракт |
|---|---|
| Балансы валют | `ResourceManager` читает и меняет `PlayerData`; сам по себе `AddResource` / `SpendResource` не пишет файл |
| XP и повышение уровня | `PlayerExperienceService`; очки за повышение выдаёт `CharacterDevelopmentService` |
| Открытия, покупки, экипировка | Отдельные списки и выбранные ID в `PlayerData` |
| Квесты | `QuestManager`, сохранённые состояния Daily/Story, признаки получения наград |
| Weekly и реклама | Журналы и ID применённых наград защищают от повторной выдачи |
| Локальное сохранение | `GameDataManager`; `ExecuteTransaction` фиксирует изменение перед публикацией событий |
| Checkpoint | `PlayerProgressCommitter.Commit` сначала вызывает локальный `SaveData`, затем уведомляет подписчиков |
| Облако | `CloudSaveSnapshot` содержит JSON `PlayerData`, владельца и время снимка |

Основные точки записи: вход в меню, завершение уровня, смена текущего уровня, покупки в магазине и покупки скинов, выбор экипировки, открытия развития, прогресс/награды/ротация квестов, подтверждение weekly-награды, реклама, уход приложения в background.

Подбор валюты меняет баланс в памяти. Покупка энергии/заряда сохраняет расход через `ExecuteTransaction` с причиной `RunRefillPurchased` до пополнения шкалы и уведомления HUD. При ошибке записи расход откатывается, пополнение не выдаётся. Обычный рестарт перезагружает сцену `Game`, сохраняя текущий `PlayerData` в памяти; неистраченные монеты предыдущей попытки входят в накопления. При аварийном завершении актуальность дискового баланса последующих подборов зависит от последнего checkpoint.

DEV-выдачи и test-level automation — служебные пути. Они учитываются отдельно от дохода игрока; automation может подавлять обычные checkpoints.

Источники: [данные игрока][player-data], [ресурсы][resources], [транзакции и сохранение][game-data], [checkpoint][committer], [причины записи][checkpoint-reasons], [background][lifecycle], [рестарт и смена уровня][level-controller], [снимок облака][cloud-snapshot].

## 9. Расчётные ориентиры

Это арифметика текущих цен; сроки получения зависят от игры и доступности наград.

| Цель | Эквивалент |
|---|---|
| Все три платных скина | 65 кристаллов и 3 очка развития |
| Те же скины только через обмен | 32 500 монет |
| Все открытия текущего каталога | 6 очков, 1440 XP |
| Только свежие Daily до всех открытий | 96 полных наборов по 15 XP |
| Один кристалл только через рекламные монеты | 10 завершённых показов по 50 монет |
| Полная энергия | 1 рекламная награда монетами |
| Полный заряд ульты | 2 рекламные награды монетами |
| Награда одного Story | 6 пополнений энергии или 3 пополнения ульты |

Первые победы со всеми звёздами кампании дают 2046 XP. Валютная стоимость скинов оплачивается отдельно. До всех улучшений требуется 2880 XP, включая остальные источники.

| Факт | Значение для экономики | Статус |
|---|---|---|
| `CollectCoin()` вызывает `CoinCollected(1)` | Coin-объекты пополняют монеты | Исправлено блоком 1; игровой прогон остаётся у пользователя |
| Покупка энергии/ульты при полном запасе | Недоступна; монеты не списываются | Исправлено 10.09.2026: проверка в механике и состояние кнопок |
| Unity Ads использует `testMode: true` | Реальная рекламная монетизация требует отдельной проверки | Подтверждено в провайдере |
| После шести открытий доступны шесть улучшений | Ещё 6 DP расходуются на уровни II/III способностей | Реализовано блоком 2 |
| Сохранение валюты забега зависит от checkpoint | Аварийное завершение может потерять последние изменения баланса | Следует из текущих границ записи |

Исторический [docs/game_economy.md](../../game_economy.md) содержит старые цены и предложения: 500 монет за рекламу, прежний обмен, прежние номера collectible-типов, оценку 176 монет за уровень. Эти значения заменяет текущий справочник.

[Концепт развития](../character-progression-and-development/Concept.md) описывает покупку скинов за монеты; текущий каталог использует кристаллы. Концепт также не раскрывает обязательный порядок открытий. Его ориентир «около двух level-up на локацию» — идея; 22 первые победы по три звезды дают 682 XP. Число повышений зависит от входящего остатка XP и дополнительных наград.

Предложения старого документа — убрать монету за перепрыгивание, выдавать 1 монету за напрыгивание, убрать случайный кристалл — текущему коду не соответствуют. В этом исследовании они не принимались как новые решения.
