## Уже есть

- Кампания: 66 уровней, 3 города по 22; по 5/5/5/7 уровней времени суток. Максимум 198 звёзд; 66 на город. Следующий город требует 64 звезды предыдущего. Источник текущего состава: economics/README.md и next_goal_cards_delivery.md от 10.09.
- На карточках отдельных уровней показаны заработанные 0–3 звезды. Модель содержит TotalStars, CompletedLevels, MasteredLevels, IsMastered на уровне города/времени суток. Общий счётчик освоения и переход к недостающим звёздам в исследованном Select не представлены.
- Story уже предлагает мастерство: завершить все уровни времени суток на три звезды. Secondary случайно выбирается среди подходящих целей мастерства/развития; это не постоянная общая цель всей кампании.
- Готова одна необязательная NextGoal-карточка на Home/Win/Select. Четыре правила: награда, доступное развитие, близкое задание, новый этап. Quest показывает только уже назначенное задание с прогрессом от 80%; Stage — открытое ещё не начатое время суток. Постоянного поиска уже пройденного уровня с 1–2 звёздами нет.
- DevelopmentNextGoalRule уже ведёт к реально доступным открытиям/апгрейдам и покупке скина. Повторная система подсказок коллекции/прокачки не нужна.
- 12 DP покрывают три платных скина по линии открытия, три способности и шесть улучшений. Это 2880 суммарных XP/уровень 13. Покупка скинов за кристаллы — отдельное действие.
- PlayerExperienceService продолжает повышать уровень каждые 240 XP; CharacterDevelopmentService.GrantForLevelUps всегда добавляет DP. Проверки исчерпания каталога при выдаче нет: после всех открытий и улучшений новые DP не имеют текущего применения.
- Story-цель следующего уровня игрока продолжает генерироваться, даёт 300 монет/0 XP. Daily даёт 5 XP за карточку; общий бонус Daily — только монеты. Первое подтверждённое weekly-улучшение дня даёт 5 XP. Повтор уровня без улучшения best-звёзд даёт 0 XP.
- Есть JourneyCompleteModal: статические призывы повышать уровень/открывать предметы/играть в рейтинге, кнопки Home/Skills/Rankings. Контроллер не проверяет исчерпание развития и не предлагает недостающие звёзды. Результат последнего уровня по IsLastAvailableLevel показывается через JourneyComplete, а не обычный Win.

## Подтверждённые практики аналогов

- [Super Mario Run, описание Nintendo в Google Play](https://play.google.com/store/apps/details?hl=en-US&id=com.nintendo.zara): повторное освоение курсов через три типа цветных монет и лучшие результаты. Переносимый принцип: дополнительная понятная цель на существующих уровнях. Для LCH уже есть звёзды; новые collectibles/карты для этого не требуются.
- [Subway Surfers, официальная справка SYBO](https://sybo.helpshift.com/hc/ru/5-subway-surfers/faq/143-missions/?p=web): после предела множителя x30 наборы миссий вознаграждаются Super Mystery Boxes. Переносимый принцип: после предела развития заменить исчерпанный тип награды полезным. Сундуки/случайный лут из примера переносить необязательно.
- [Jetpack Joyride, официальная справка Halfbrick](https://halfbrick.helpshift.com/hc/en/4-jetpack-joyride/faq/723-how-do-i-earn-prestige-badges/): каждые 15 уровней миссий дают Prestige Badge, всего 125. Это пример продолжения метапрогресса после одного цикла. Для текущего минимального объёма LCH отдельную коллекцию badge/prestige не предлагаем.

Источники подтверждают наличие механик, а не измеренный прирост retention именно от них. Применимость к LCH и суммы ниже — наш вывод, не утверждение источников.

## Утверждённый минимум: две доработки

### 1. Довести существующую кампанию до трёх звёзд

- После прохождения всех уровней при оставшихся 1–2-звёздочных результатах существующая NextGoal-карточка может предложить «Собрано 184/198 звёзд» и «Добрать звёзды». 184 — пример; числитель/предел вычисляются по сохранённому прогрессу и активному каталогу.
- Кнопка открывает существующий Select на конкретном уже открытом уровне с 1–2 звёздами. Выбирать стабильный первый подходящий уровень по каталогу; автозапуск не требуется. После Win цель перечитывается из сохранённого best.
- Это общий ориентир мастерства; существующие Story остаются владельцем своих условий/наград. Дополнительных выплат за тот же сбор звёзд не вводить.
- Использовать нынешние приоритеты, закрытие карточки и маршруты. Готовая награда/урок имеют приоритет; отдельного нового экрана и второго координатора целей не требуется.
- В JourneyComplete показать актуальную следующую цель/переход к недостающим звёздам. Уже завершённые открытия и улучшения не предлагать. При полном освоении карточка добора исчезает; повторные циклы поддерживаются уже существующими активностями/рейтингом.
- Польза-гипотеза: после последнего уровня игрок видит конкретную следующую попытку, а не ищет недобор вручную среди городов/времени суток.

### 2. Полезная награда за LevelUp после полного развития

- Пока по каталогу есть неоткрытые предметы либо недостигнутые максимальные уровни способностей, сохранять текущую выдачу DP и темп XP.
- После фактического завершения всех этих открытий/улучшений утверждён стартовый вариант: **50 монет за очередные 240 XP вместо 1 DP**. Player Level продолжает расти. Проверка по завершённости каталога, а не только PlayerLevel>=13 и не по текущему CanUpgrade/доступному балансу.
- 50 монет — согласованная пробная настройка, не доказанный оптимум. Это размер существующей магазинной рекламной награды. При иллюстративных 15 XP Daily +5 XP weekly за активный день: 240/20=12 таких дней на LevelUp, 50/12≈4,17 дополнительной монеты/день. Это около 7% от 60 монет полного Daily. Story/оставшиеся звёзды меняют интервал; это не общий прогноз дохода или календарного retention.
- Существующее окно LevelUp показывает фактически выданные монеты. Выдача сохраняется вместе с XP/уровнем текущей транзакцией; открытие/повтор окна награду не создаёт. Исторические уже выданные DP задним числом автоматически не конвертировать.
- Новая сумма относится только к исчерпанному развитию; это не дополнительная выплата за каждый рекорд и не изменение дневного XP-лимита блока 4.
- Польза-гипотеза: выполнение Daily и улучшение рекордов сохраняет понятную пользу XP после исчерпания DP. Монеты расходуются на существующие пополнения ресурсов.

## Уточнения пользователя: будущие паки и существующий UI

- Планируется синхронный выпуск новых локаций, скинов и способностей с их улучшениями. Ориентир — один новый скин и одна способность на новую локацию; количество, сроки и состав конкретных паков ещё не заданы. Создание нового контента не входит в эту задачу.
- После появления новых открытий/улучшений в актуальном каталоге последующие LevelUp снова дают DP. После исчерпания нового развития — снова монеты. Состояние определяется каталогом и прогрессом; фиксированный уровень 13 или список нынешних трёх предметов не служат условием.
- Незавершённая покупка уже открытого скина за кристаллы сама по себе не означает оставшийся расход DP. Готовность каталога проверяется до решения о награде; отсутствие данных не означает «всё развито».
- Количество уровней и максимум звёзд вычисляются из активного каталога. При выходе пака пересчитываются доступные цели; прежние earned-звёзды сохраняются. Числа 66/198 описывают обследованную версию, не константы реализации.
- UI-ограничение явно подтверждено: используются только существующие карточка цели, JourneyComplete, LevelUp и их элементы. Меняются содержимое, иконки и действия имеющихся кнопок. Новые окна, дополнительные панели/кнопки/счётчики и отдельные UI-элементы не добавляются.
- В JourneyComplete под актуальный переход переиспользуется имеющаяся кнопка. В LevelUp отображается фактическая награда сохранённого повышения. Если после выдачи монет вышел новый пак, прежнее неподтверждённое окно всё равно показывает выданные монеты; пересчёт прошлого начисления по новому каталогу недопустим.

## Границы и оценка

- Первые 12 DP, кривая XP, стоимость скинов/апгрейдов и выплаты блоков 3–4 сохраняются до отдельного согласования.
- Престиж со сбросом, бесконечные уровни способностей, новая коллекция, ивенты и отдельные валюты не входят в минимум по запросу пользователя.
- Мастерство конечно: к Barcelona первые два города уже требуют минимум 128/132 звезды. После всех 66 побед минимум 150/198 звёзд; максимум недобора 48. Это ограниченный запас перепрохождения, не обещание удержания на месяцы. Долгие повторные циклы уже покрывают Daily/активности/рейтинг.
- Будущая проверка пользы: переходы из цели к уровню, повторные победы/улучшение best после конца кампании, возвраты завершивших кампанию; для второй доработки — игроки с полным развитием, участие в XP-активностях и дополнительный валютный приток. До наблюдений фиксируем гипотезы, не проценты прироста.
- Владелец сначала сохраняет короткий план с отдельными задачами в `docs/products/economics/long_term_plan.md`, затем автономно реализует весь утверждённый объём. Итог — `long_term_implementation.md`: свой scope, результаты компиляции/review, существенные ограничения и commit/push.
- Требования пользователя: экономить токены и действия без потери качества; SOLID/DRY/KISS, встроенная архитектура, устранение причины без костылей и лишних универсальных систем. Использовать готовое исследование; повторно изучать только затронутые актуальные контракты.
- После реализации обязательны необходимая компиляция и code review на качество/явные ошибки/недосмотры; найденное исправить. Долгие проверки, ручные UI/Play/phone и сборки ради проверки не требуются, ручная приёмка у пользователя.
- Commit/push разрешены после готовности и проверок. В общем checkout Git меняет один владелец последовательно, только собственные завершённые изменения; чужой dirty и generated-шум сохраняются. Обычный push с подтверждением remote, без force. При изменении remote C# повторять только затронутый compile/review.
