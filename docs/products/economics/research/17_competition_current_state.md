## Реализовано

- 12 настроенных таблиц: 3 города × 4 времени суток. UI открывает доступные по кампании города/время; переключение стрелками и четырьмя вкладками.
- В таблицу времени суток отправляется score одного успешного уровня. Сохраняется лучший недельный забег; результаты разных уровней времени суток не суммируются.
- Score: подобранная монета +1; подобранные кристалл/энергетик/пицца/жизнь +2; разрушенное препятствие +3, включая разрушение способностью. Это очки рейтинга, отдельные от валют и XP. Обычное перепрыгивание отдельного score в RunScoreMechanics не даёт.
- Score виден в HUD и Win. Поражение без последующего успешного продолжения не отправляет результат.
- В HUD уже есть однократное пересечение известного личного weekly-рекорда с пояснением «Победи, чтобы отправить». Подтверждённый рекорд/первая запись имеют отдельные существующие уведомления.
- Win показывает score попытки и weekly best после разрешения отправки. На последнем уровне времени суток кнопка рейтинга заменяет строку weekly best. На других уровнях эта кнопка скрыта. Из Win рейтинг открывается на соответствующих городе/времени суток.
- Экран рейтинга показывает TOP-50: место, имя, очки. Своя строка выделена внутри TOP-50; вне TOP-50 закреплена отдельно снизу. Ближайших соперников за пределами TOP-50 сервис не запрашивает.
- Уже видны диапазон дат недели, сохранённость/давность таблицы, обновление, отсутствие личной записи, состояние отправки/профиля. Даты берутся из server NextReset; живой reset отдельно не проверялся.
- Просмотр предусмотрен для гостя; участие зависит от подтверждённого владельца профиля. Кеш/повтор/разделение общей и личной таблицы уже реализованы.
- Первое подтверждённое личное улучшение за UTC-день даёт 5 XP; следующие 0. Лимит общий по таблицам owner/environment в локальном журнале. Первая запись также проходит как улучшение. Между независимыми устройствами строгой общей квоты нет.
- В UI нет правил score и действия «Играть/Побить рекорд» из выбранной таблицы. Общее сообщение без записи лишь предлагает пройти уровень.
- Пользовательской истории недель и наград за итоговое место нет. Технические журналы/кеш не являются историей итоговых мест.

## Утверждённые три доработки

1. Краткое объяснение существующего рейтинга: лучший победный забег недели для выбранного города/времени; +1/+2/+3 за действия; действующая награда 5 XP за первое подтверждённое улучшение дня. Использовать компактную подсказку на существующем экране.
2. Действие «Побить рекорд» / «Установить рекорд» из рейтинга. Открывать существующий выбор уровня на выбранных городе/времени суток, сохраняя доступность уровней. Личный score уже есть — новую систему личных заданий для этого не создавать. Состояние устаревших данных сохраняет существующее обозначение.
3. Небольшая правка Win: на последнем уровне времени суток оставить лучший результат/новый рекорд видимым рядом с переходом к таблице. Переиспользовать текущие элементы; отдельное поздравительное окно не требуется.

В согласованный объём входят только эти три пункта. Действующие XP сохраняются. Награды за места, история сезонов и запрос соседних позиций остаются вне текущего плана.

Особенность до обсуждения призов за места: разные уровни одного времени суток делят таблицу, а score зависит от количества доступных объектов и разрушений. Предполагаемое преимущество более насыщенных уровней следует из формулы; реальный разброс/честность сравнения не измерены. Формулу и разбиение таблиц этим предложением не меняем.
