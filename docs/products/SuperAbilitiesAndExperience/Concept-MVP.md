# XP и суперудары — концепт MVP

## 1. Шкурки: независимая косметика

- Экран шкурок и его UX не меняются.
- Шкурки приобретаются за кристаллы.
- Купленная шкурка активируется существующей кнопкой `Надеть`.
- Шкурка меняет только внешний вид хомяка.
- Шкурка не открывает, не усиливает и не выбирает суперудар.
- Выбор шкурки не меняет активный суперудар.
- Выбор суперудара не требует конкретной шкурки.

## Продуктовые фичи концепта

1. **Шкурки как косметика** — магазин за кристаллы, выбор `Надеть`, без связи с суперударами.
2. **XP и уровни** — награды за звёзды, рекорды и квесты; накопление XP, перенос остатка, Level Up.
3. **Суперудары: открытие и выбор** — Level открывает способность; экран «Суперудары»; один активный суперудар.
4. **UI прогресса и награды** — XP-панель в меню, баннер после победы, отдельное окно Level Up.
5. **Применение суперудара в забеге** — отображение и нажатие активного суперудара в gameplay, его эффект и ограничения.

## 2. Разделение прогрессий

- **Счёт:** результат забега и лидерборд.
- **Звёзды:** прогресс прохождения; открытие уровней, частей дня и локаций.
- **XP:** постоянный прогресс игрока; повышение Level и открытие суперударов.
- **Монеты:** отдельный игровой ресурс; не открывает суперудары.
- **Кристаллы:** покупка шкурок; не открывают суперудары.
- **Квесты:** дополнительный источник XP.

## 3. XP-экономика

### Награды

| Источник | Награда |
|---|---:|
| 1 звезда за уровень | `10 XP` |
| 2 звезды за уровень | `20 XP` |
| 3 звезды за уровень | `30 XP` |
| Новый личный рекорд по очкам | `50 XP` |
| Дневной квест | `20 XP` |
| Длинный сюжетный квест | `60 XP` |

Все награды заполняют одну XP-шкалу текущего Level.

### XP за звёзды

- Одна звезда стоит `10 XP`.
- При первом успешном прохождении начисляется XP за полученные звёзды.
- Повторное прохождение даёт XP только при улучшении лучшего результата по звёздам.
- Начисляется только разница до нового максимума.
- Максимум с одного уровня за всё время — `30 XP`.

```text
XP за улучшение = max(0, новые лучшие звёзды - старые лучшие звёзды) × 10
```

Примеры:

- Сначала 1 звезда: `+10 XP`. Позже 3 звезды: ещё `+20 XP`.
- Сначала 2 звезды: `+20 XP`. Позже 3 звезды: ещё `+10 XP`.
- Те же или меньшие звёзды: `+0 XP`.

### Антифарм

- Полученный максимум звёзд нельзя повторно конвертировать в XP.
- Счёт забега не конвертируется в XP напрямую.
- Score-множители не умножают XP.
- `50 XP` начисляются только при новом личном рекорде.
- Отдельного XP за достижения в MVP нет.

Пример комбинированной награды:

```text
НОВЫЙ РЕКОРД: +50 XP
УЛУЧШЕНИЕ С 1 ДО 3 ЗВЁЗД: +20 XP
ИТОГО: +70 XP
```

## 4. Level Up и разблокирование суперударов

### Прогресс Level

- UI показывает `текущий XP / порог текущего Level`.
- Проценты отдельно не показываются.
- При достижении порога происходит Level Up.
- Шкала следующего Level начинает новый цикл.
- Излишек XP от одной награды не теряется и переносится в новую шкалу.

```text
Было: 235/240 XP
Награда: +10 XP
Level Up
Новая шкала: 5 XP
```

### Первый Level Up

- Первый порог — `240 XP`.
- Первый Level Up сразу открывает первый суперудар.
- Morning содержит 3 уровня, Day — 5 уровней.
- Все 8 уровней на 3 звезды дают `8 × 3 × 10 = 240 XP`.
- Первый суперудар гарантированно открывается через Morning + Day на 3 звезды.
- Квесты и личные рекорды для открытия первого суперудара не обязательны.

### Правила разблокирования

- Суперудар открывается автоматически при достижении нужного Level.
- Открытый суперудар сразу доступен для выбора.
- Покупка после открытия не нужна.
- Дополнительный квестовый барьер после открытия не нужен.
- На `Level Up Modal` показываются новый Level и открытый суперудар.

## 5. Пользовательский flow

### От меню до результата

1. Главное меню показывает текущие Level и XP.
2. Нажатие на XP-панель открывает экран «Суперудары».
3. Игрок завершает игровой уровень.
4. Начисляется XP за звёзды, новый рекорд и завершённые квесты.
5. Открывается `WinModal`.
6. Сверху поверх `WinModal` выезжает временный XP-баннер.
7. На баннере появляется `+N XP`.
8. XP-полоса анимированно заполняется.
9. Баннер уезжает вверх.

XP-полоска не добавляется внутрь `WinModal` и не показывается во время забега.

### Без Level Up

1. Игрок выбирает `Home`, `Retry` или `Continue`.
2. Действие выполняется обычным образом.

### С Level Up

1. Игрок выбирает `Home`, `Retry` или `Continue` в `WinModal`.
2. Действие ставится в очередь.
3. `WinModal` закрывается.
4. Открывается отдельная `Level Up Modal`.
5. Показываются `УРОВЕНЬ N → N+1`, карточка суперудара и текст `Суперудар доступен`.
6. Игрок нажимает единственную кнопку `OK`.
7. `Level Up Modal` закрывается.
8. Выполняется ранее выбранное действие.

Кнопки перехода в «Суперудары» на `Level Up Modal` нет.

### Выбор активного суперудара

1. Игрок открывает «Суперудары» через XP-панель главного меню.
2. Экран показывает активную, доступную и закрытую карточки.
3. Игрок нажимает `Выбрать` на доступной карточке.
4. Новая способность получает статус `✓ Активен`.
5. Предыдущая способность теряет активный статус.

Одновременно активен только один суперудар. Выбор выполняется только через CTA `Выбрать`; нажатие на карточку не меняет выбор.

## 6. UI

### 6.1 Верхний HUD главного меню

- HUD занимает одну компактную высоту.
- Слева рядом с `DEF` находятся монеты и кристаллы без кнопок `+`.
- По центру находится кликабельная XP-панель.
- В панели находятся `УР. 1`, XP-bar и `170 / 240`.
- `XP` — небольшая метка внутри бара, не большие буквы поверх полосы.
- Нажатие на панель открывает «Суперудары».
- Справа находится `Settings`.
- Магазин открывается отдельной нижней кнопкой `M`.

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ [DEF] [🪙 1 250] [💎 24]   [ УР. 1 | XP ████████░░░░ 170 / 240 ]   [⚙] │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 6.2 XP-баннер после победы

- Баннер — временный горизонтальный overlay поверх верхней части `WinModal`.
- Баннер показывает текущий Level, `текущий XP / порог` и XP-bar.
- Поверх баннера появляется `+N XP`, затем растворяется.
- Полоса анимированно заполняется.
- После анимации баннер уезжает вверх.
- `WinModal` остаётся без встроенной XP-полоски.

```text
          ВРЕМЕННЫЙ XP OVERLAY ПОВЕРХ WINMODAL
     +--------------------------------------------------+
     | LEVEL 1       [============--------]  220/240 XP |
     |                        +20 XP                    |
     +--------------------------------------------------+
                         ↓ заполнение

+------------------------------------------------------------+
|                         WINMODAL                           |
|                  ИГРОВОЙ УРОВЕНЬ 8                        |
|                                                            |
|                         *  *  *                            |
|                                                            |
|                    СЧЁТ: 1 250                             |
|                                                            |
|              [ HOME ] [ RETRY ] [ CONTINUE ]               |
+------------------------------------------------------------+

После анимации XP-баннер уезжает вверх. WinModal остаётся.
```

### 6.3 Level Up Modal

```text
+------------------------------------------------------------+
|                       LEVEL UP!                            |
|                                                            |
|                     УРОВЕНЬ 1 → 2                          |
|                                                            |
|               +------------------------+                   |
|               |        [ИКОНКА]        |                   |
|               |      СУПЕРУДАР 1       |                   |
|               |                        |                   |
|               |  СУПЕРУДАР ДОСТУПЕН   |                   |

В очереди: CONTINUE
OK закрывает модалку → выполняется CONTINUE
```

- Единственный CTA — `OK`.
- Перехода в «Суперудары» нет.

### 6.4 Landscape-экран «Суперудары»

- Сверху слева — `Back`.
- Сверху по центру — `СУПЕРУДАРЫ`.
- Крупно показывается текущий Level.
- Рядом показываются XP-bar и `текущий XP / порог`.
- Ниже находятся три карточки суперударов.
- Карточка содержит иконку, название, статус, Level/замок и XP-порог.

```text
+--------------------------------------------------------------------------------+
| [< BACK]                         СУПЕРУДАРЫ                                     |
|                                                                                |
|                         LEVEL 2                                                |
|                 [================------]  180 / 240 XP                          |
|            Получай XP, повышай Level, открывай суперудары                      |
|                                                                                |
| +----------------------+ +----------------------+ +----------------------+     |
| |       [ИКОНКА]       | |       [ИКОНКА]       | |       [ЗАМОК]        |     |
| |     СУПЕРУДАР 1      | |     СУПЕРУДАР 2      | |     СУПЕРУДАР 3      |     |
| |    ✓ АКТИВЕН         | |       ДОСТУПЕН       | |       ЗАКРЫТ         |     |
| |  ОТКРЫТ: LEVEL 2     | |  ОТКРЫТ: LEVEL 2     | |    НУЖЕН LEVEL N     |     |
| |    ПОРОГ: 240 XP     | |     ПОРОГ: N XP      | |     ПОРОГ: N XP      |     |
| |  зелёное выделение   | |     [ ВЫБРАТЬ ]       | |       [ЗАМОК]        |     |
| +----------------------+ +----------------------+ +----------------------+     |
+--------------------------------------------------------------------------------+
```

### Состояния и CTA карточек

- **Активная:** зелёное выделение и `✓ Активен`.
- **Доступная:** кнопка `Выбрать`.
- **Закрытая:** замок, необходимый Level и XP-порог; CTA выбора отсутствует.
- Термины `Надеть` и `Включить` для суперударов не используются.
