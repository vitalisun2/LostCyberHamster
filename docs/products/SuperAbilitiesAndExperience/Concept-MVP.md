# SuperAbilities и Experience — Concept MVP

## Шкурки: независимая косметика

Шкурки — независимая косметика. Экран шкурок и кнопка `Надеть` не меняются, покупки выполняются за кристаллы. Будущая реализация полностью отделяет skins от SuperAbilities в коде, базе данных и сохранениях.

### Продуктовое поведение

- Шкурка меняет только внешний вид хомяка.
- Купленная шкурка активируется существующей кнопкой `Надеть`.
- Шкурка не открывает, не усиливает и не выбирает суперудар.
- Выбор шкурки не меняет активный суперудар.
- Выбор суперудара не требует конкретной шкурки.
- Визуальные эффекты шкурки не должны ухудшать читаемость суперудара.

### Техническая граница будущей реализации

- `Skin` и `SuperAbility` — отдельные сущности.
- Владение шкурками хранится отдельно от открытых SuperAbilities.
- Выбранная шкурка хранится отдельно от активной SuperAbility.
- Покупка шкурки не создаёт unlock SuperAbility.
- Открытие SuperAbility не создаёт владение шкуркой.
- Общих purchase/unlock-зависимостей между системами быть не должно.
- Главная техническая задача — удалить текущую связанность из логики кода, базы данных и сохранений.
- Миграция старых связок «шкурка + суперудар» требует отдельного безопасного плана.

## 1. Цель и границы фичи

### Цель

- Дать игроку постоянное развитие между уровнями.
- Вознаграждать качественное прохождение, рекорды и квесты.
- Через Level Up открывать новые игровые способности.
- Объяснить связь `XP → Level → суперудар` одним понятным flow.

### Границы

- **Счёт:** результат забега и лидерборд.
- **Звёзды:** прогресс прохождения; открытие уровней, частей дня и локаций.
- **XP:** постоянный прогресс игрока; повышение Level и открытие суперударов.
- **Монеты:** существующий игровой ресурс; не открывает суперудары.
- **Кристаллы:** покупка шкурок; не открывают суперудары.
- **Квесты:** дополнительный источник XP.

### Суперудары

- Суперудар — отдельная игровая способность.
- Суперудар открывается по Level и сразу становится доступен.
- После открытия нет покупки, обязательного квеста или второго барьера.

### Активная способность

- Одновременно активен только один суперудар.
- Открытая неактивная карточка имеет основной CTA `Выбрать`.
- Активная карточка выделена и показывает зелёную отметку `✓ Активен`.
- Закрытая карточка показывает замок, необходимый Level и XP-порог.
- Нажатие на открытую карточку тоже может выбрать способность.
- Кнопка `Выбрать` остаётся основным явным CTA.
- Термины `Надеть` и `Включить` не используются для суперударов.

### Не входит в первую версию

- Отдельная система достижений: она дублирует квесты.
- Покупка суперударов за монеты или кристаллы.
- Кнопка перехода в «Суперудары» из `Level Up Modal`.
- Окончательная дорожка, дерево или другая структура дальнейшей прогрессии.

## 2. Как зарабатывается XP

### Источники и стартовые награды

| Источник | Награда |
|---|---:|
| 1 звезда за уровень | `10 XP` |
| 2 звезды за уровень | `20 XP` |
| 3 звезды за уровень | `30 XP` |
| Новый личный рекорд по очкам | `50 XP` |
| Дневной квест | `20 XP` |
| Длинный сюжетный квест | `60 XP` |

Все награды заполняют одну XP-шкалу текущего Level.

### XP за звёзды

- Одна звезда стоит `10 XP`.
- При первом успешном прохождении начисляется XP за полученные звёзды.
- Повторное прохождение даёт XP только при улучшении лучшего результата по звёздам.
- Начисляется только разница до нового максимума.
- Максимум с одного уровня за всё время — `30 XP`.

```text
XP за улучшение = max(0, новые лучшие звёзды - старые лучшие звёзды) × 10
```

Примеры:

- Сначала 1 звезда: `+10 XP`. Позже 3 звезды: ещё `+20 XP`.
- Сначала 2 звезды: `+20 XP`. Позже 3 звезды: ещё `+10 XP`.
- Те же или меньшие звёзды: `+0 XP`.

### Антифарм

- Уже полученный максимум звёзд нельзя бесконечно конвертировать в XP.
- Счёт забега не конвертируется в XP напрямую.
- Score-множители не умножают XP.
- Бонус `50 XP` выдаётся только при новом личном рекорде.
- Начисление XP, обновление рекорда и сохранение должны быть однократными и согласованными.

Пример комбинированной награды:

```text
НОВЫЙ РЕКОРД: +50 XP
УЛУЧШЕНИЕ С 1 ДО 3 ЗВЁЗД: +20 XP
ИТОГО: +70 XP
```

## 3. Прогресс Level и Level Up

### Шкала текущего Level

- UI показывает `текущий XP / порог текущего Level`.
- Проценты отдельно не показываются.
- При достижении порога происходит Level Up.
- После Level Up начинается шкала следующего Level.
- Излишек одной награды не теряется и переносится в новую шкалу.

```text
Было: 235/240 XP
Награда: +10 XP
Level Up
Новая шкала: 5 XP
```

Логика переноса:

```text
currentLevelXP += rewardXP

while currentLevelXP >= currentThreshold:
    currentLevelXP -= currentThreshold
    Level += 1
    применить открытия нового Level
```

### Первый Level Up

- Первый порог — `240 XP`.
- Первый Level Up сразу открывает первый суперудар.
- Morning содержит 3 уровня, Day — 5 уровней.
- Все 8 уровней на 3 звезды дают `8 × 3 × 10 = 240 XP`.
- Первый суперудар гарантированно открывается через Morning + Day на 3 звезды.
- Квесты и личные рекорды для этого не обязательны.

### Открытие способности

- Достигнут нужный Level — суперудар открыт автоматически.
- Открытый суперудар сразу доступен для выбора.
- Покупка после открытия не нужна.
- На `Level Up Modal` показывается карточка нового суперудара и текст `Суперудар доступен`.

## 4. Пользовательский flow

### Основной путь

1. Главное меню показывает текущие Level и XP.
2. Нажатие на XP-панель открывает landscape-экран «Суперудары».
3. Игрок запускает и завершает игровой уровень.
4. Игра считает XP за улучшение звёзд, новый рекорд и завершённые квесты.
5. Открывается `WinModal`.
6. Сверху поверх `WinModal` выезжает временный XP-баннер.
7. На баннере появляется `+N XP`, затем заполняется progress bar.
8. Баннер уезжает вверх. XP-полоска не остаётся внутри `WinModal`.

### Ветка без Level Up

1. Игрок выбирает `Home`, `Retry` или `Continue`.
2. Выбранное действие выполняется обычным образом.

### Ветка с Level Up

1. Игрок выбирает `Home`, `Retry` или `Continue` в `WinModal`.
2. Действие ставится в очередь и пока не выполняется.
3. `WinModal` закрывается.
4. На её месте открывается отдельная `Level Up Modal`.
5. Модалка показывает `УРОВЕНЬ N → N+1`.
6. Показывается карточка нового суперудара и подпись `Суперудар доступен`.
7. На модалке есть только кнопка `OK`.
8. Игрок нажимает `OK`.
9. `Level Up Modal` закрывается.
10. Выполняется ранее выбранное действие.

Перехода в «Суперудары» из `Level Up Modal` нет.

### Выбор активного суперудара

1. Игрок открывает «Суперудары» через XP-панель главного меню.
2. Экран показывает три карточки: активную, доступную и закрытую.
3. Игрок нажимает `Выбрать` на доступной карточке.
4. Новая способность получает статус `✓ Активен`.
5. Предыдущая способность теряет активный статус.
6. Альтернативно открытая карточка может выбираться нажатием по самой карточке.

## 5. UI по моментам

### 5.1 Верхний HUD главного меню

- Landscape HUD занимает одну компактную высоту.
- Слева рядом с `DEF` находятся монеты и кристаллы.
- У ресурсов нет кнопок `+`.
- По центру находится кликабельная XP-панель.
- В панели находятся `УР. 1`, progress bar и `170 / 240`.
- `XP` — небольшая метка внутри бара, не большие буквы поверх полосы.
- Нажатие на панель открывает «Суперудары».
- Справа находится `Settings`.
- Магазин позже открывается отдельной нижней кнопкой `M`.

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ [DEF] [🪙 1 250] [💎 24]   [ УР. 1 | XP ████████░░░░ 170 / 240 ]   [⚙] │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 XP-баннер после победы

- Баннер — отдельный временный overlay поверх верхней части `WinModal`.
- Баннер показывает текущий Level, `текущий XP / порог` и progress bar.
- Поверх баннера появляется `+N XP`.
- `+N XP` растворяется.
- Полоса анимированно заполняется.
- После анимации баннер уезжает вверх.
- XP-полоска не добавляется внутрь `WinModal`.
- Во время самого забега XP не показывается.

```text
          ВРЕМЕННЫЙ XP OVERLAY ПОВЕРХ WINMODAL
     +--------------------------------------------------+
     | LEVEL 1       [============--------]  220/240 XP |
     |                        +20 XP                    |

|                                                            |
|              [ HOME ] [ RETRY ] [ CONTINUE ]               |
+------------------------------------------------------------+

После анимации XP-баннер уезжает вверх. WinModal остаётся.
```

### 5.4 Landscape-экран «Суперудары»

Единый экран объясняет связь `XP → Level → способности`.

- Сверху слева — `Back`.
- Сверху по центру — `СУПЕРУДАРЫ`.
- Крупно — текущий Level.
- Ниже или рядом — XP progress bar и `текущий XP / порог`.
- Ниже — три карточки суперударов в один ряд.
- Карточка содержит иконку, название, статус, Level/замок и XP-порог.

## 6. Экономика и настраиваемые значения

### Стартовая конфигурация

| Параметр | Значение |
|---|---:|
| XP за одну звезду | `10` |
| Максимум XP за звёзды одного уровня | `30` |
| XP за новый личный рекорд | `50` |
| XP за дневной квест | `20` |
| XP за длинный сюжетный квест | `60` |
| Порог первого Level Up | `240` |

### Балансовые ориентиры

- Morning + Day на 3 звезды дают ровно `240 XP`.
- Новый рекорд равен 5 звёздам.
- Дневной квест равен 2 звёздам.
- Длинный сюжетный квест равен 6 звёздам.
- Значения стартовые и должны оставаться настраиваемыми.
- Баланс проверяется по темпу первого открытия и дальнейшей XP-кривой.
- Излишек XP между Level не теряется.

### Разделение экономики

- Монеты не открывают суперудары.
- Кристаллы покупают шкурки, но не суперудары.
- XP открывает суперудары, но не покупает шкурки.
- Звёзды сохраняют роль открытия игрового контента.
- Квесты поддерживают XP-прогрессию.

### Риски

- Слишком быстрый или медленный XP-темп.
- Повторное начисление XP из-за неатомарного сохранения.
- Потеря излишка XP при Level Up.
- Потеря ранее доступных суперударов при миграции.
- Скрытая зависимость старого суперудара от данных шкурки.
- Путаница между игровым уровнем, Level игрока, счётом и XP.
- Несовместимые визуальные эффекты шкурок и суперударов.
- Три карточки и XP-блок могут не поместиться на малых landscape-экранах.
