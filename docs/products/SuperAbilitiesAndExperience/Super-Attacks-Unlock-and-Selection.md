# Super Attacks: Unlock and Selection

## 1. Целевое поведение

- Существующие суперудары сохраняют прежние gameplay-логику, заряд, эффекты и параметры.
- Суперудары работают независимо от выбранной шкурки.
- `PlayerLevel` открывает суперудары.
- Первый Level Up открывает первый суперудар.
- Открытый суперудар получает статус `Доступен` и ждёт CTA `Выбрать`.
- Только CTA `Выбрать` меняет активный суперудар.
- До первого выбора `active ID` пустой. В забеге кнопка суперудара скрыта.
- Первый выбор сохраняет `active ID` и подключает выбранный суперудар к забегу.
- Следующий выбор заменяет `active ID`. Активный суперудар всегда один.
- XP-панель открывает отдельный экран «Суперудары».
- Экран и Level Up используют один `SuperAttackService`. Gameplay получает выбранный runtime.

### С Level Up

1. Игрок выбирает `Home`, `Retry` или `Continue` в `WinModal`.
2. Действие ставится в очередь.
3. `WinModal` закрывается.
4. Открывается отдельная `Level Up Modal`.
5. Показываются `УРОВЕНЬ N → N+1`, карточка суперудара и текст `Суперудар доступен`.
6. Игрок нажимает единственную кнопку `OK`.
7. `Level Up Modal` закрывается.
8. Выполняется ранее выбранное действие.

### Выбор активного суперудара

1. Игрок открывает «Суперудары» через XP-панель.
2. Экран показывает активные, доступные и закрытые карточки.
3. Игрок нажимает `Выбрать` на доступной карточке.
4. Карточка получает статус `✓ Активен`.
5. Предыдущая активная карточка получает статус `Доступен`.

|               +------------------------+                   |

- Единственный CTA — `OK`.
- Перехода в «Суперудары» нет.

### 6.4 Landscape-экран «Суперудары»

- Сверху слева — `Back`.
- Сверху по центру — `СУПЕРУДАРЫ`.
- Крупно показывается текущий Level.
- Рядом показываются XP-bar и `текущий XP / порог`.
- Ниже находятся три карточки суперударов.
- Карточка содержит иконку, название, статус, Level/замок и XP-порог.

```text
+--------------------------------------------------------------------------------+
| [< BACK]                         СУПЕРУДАРЫ                                     |
|                                                                                |
|                         LEVEL 2                                                |
|                 [================------]  180 / 240 XP                          |
|            Получай XP, повышай Level, открывай суперудары                      |
|                                                                                |
| +----------------------+ +----------------------+ +----------------------+     |
| |       [ИКОНКА]       | |       [ИКОНКА]       | |       [ЗАМОК]        |     |
| |     СУПЕРУДАР 1      | |     СУПЕРУДАР 2      | |     СУПЕРУДАР 3      |     |
| |    ✓ АКТИВЕН         | |       ДОСТУПЕН       | |       ЗАКРЫТ         |     |
| |  ОТКРЫТ: LEVEL 2     | |  ОТКРЫТ: LEVEL 2     | |    НУЖЕН LEVEL N     |     |
| |    ПОРОГ: 240 XP     | |     ПОРОГ: N XP      | |     ПОРОГ: N XP      |     |
| |  зелёное выделение   | |     [ ВЫБРАТЬ ]       | |       [ЗАМОК]        |     |
| +----------------------+ +----------------------+ +----------------------+     |
+--------------------------------------------------------------------------------+
```

### Состояния и CTA карточек

- **Активная:** зелёное выделение и `✓ Активен`.
- **Доступная:** кнопка `Выбрать`.
- **Закрытая:** замок, необходимый Level и XP-порог; CTA выбора отсутствует.
- До первого выбора все открытые карточки имеют статус `Доступен`.
- После первого выбора ровно одна карточка имеет статус `✓ Активен`.

## 2. Текущее состояние

- До отделения суперудар был частью `Skin`.
- `SkinData` хранил prefab эффекта, длительность и заряд.
- `EnergyShieldSkin` и `ElectricStrikeSkin` содержали gameplay-логику суперударов.
- `UltaMechanics`, `UltaChargeMechanics`, `Hamster.UltaEvent` и `UltaChargeAmount` управляли зарядом и применением.
- После отделения `Skin` хранит только косметику.
- `EnergyShieldAttack` и `ElectricStrikeAttack` уже сохраняют прежнюю логику щита и электрического удара.
- `UltaMechanics` и `UltaChargeMechanics` уже принимают данные суперудара отдельно от шкурки.
- Прежние ID: щит — `1`, электрический удар — `2`.

## 3. Нужно изменить

- Закрепить существующие `EnergyShieldAttack` и `ElectricStrikeAttack` как самостоятельные суперудары.
- Использовать прежние эффекты, длительность, заряд и gameplay-логику.
- Добавить общий runtime-контракт для существующих суперударов: заряд, применение и обновление.
- Перенести прежние ID, эффект, длительность и заряд в отдельный JSON суперударов.
- Добавить к записи адрес иконки и `RequiredPlayerLevel`.
- Связать прежний ID с существующей runtime-реализацией через фабрику.
- Новый суперудар добавляется записью JSON, ассетами, runtime-классом и регистрацией в фабрике.
- Сохранять `active ID` в `PlayerData`.
- Вычислять открытие по `PlayerLevel`.
- Передавать выбранный runtime в `Hamster.ConfigureSuperAttack(activeAttack)`.
- Строить карточки экрана из того же каталога.

## 4. Шаги реализации

1. **Отделить суперудары от шкурок.**
   - Существующие щит и электрический удар подключаются через общий runtime-контракт.
   - `Skin` отвечает за внешний вид. Суперудар отдельно хранит прежние эффект, заряд, длительность и поведение.

2. **Добавить открытие по Level.**
   - `SuperAttackService` загружает отдельный JSON с прежними ID и runtime-параметрами.
   - Щит открывается на `PlayerLevel 2`, электрический удар — на `PlayerLevel 3`.
   - Сервис вычисляет доступность по текущему `PlayerLevel`.
   - `PlayerExperienceService` начисляет XP и повышает `PlayerLevel`.

3. **Добавить выбор суперудара.**
   - CTA `Выбрать` передаёт ID открытой карточки в `SuperAttackService`.
   - `SuperAttackService` проверяет доступность и делает этот суперудар активным.

4. **Сохранять выбор.**
   - `PlayerData` хранит `ActiveSuperAttackId`.
   - Первый выбор записывает ID. Следующий выбор заменяет его.
   - `PlayerProgressCommitter` сохраняет изменение.

5. **Добавить экран «Суперудары».**
   - `SuperAttacksScreenController` строит карточки из данных `SuperAttackService`.
   - `PlayerLevel` и `ActiveSuperAttackId` определяют состояния `Закрыт`, `Доступен` и `Активен`.
   - XP-панель открывает экран.

6. **Связать выбор с забегом.**
   - `SuperAttackFactory` создаёт существующую механику по `ActiveSuperAttackId`.
   - Runtime передаётся в `Hamster.ConfigureSuperAttack`.
   - `Hamster`, заряд, активация и эффекты работают по прежней схеме.
   - Пустой ID скрывает кнопку суперудара.

7. **Добавить показ при Level Up.**
   - Новый `PlayerLevel` проверяется через `SuperAttackService`.
   - `Level Up Modal` показывает карточку открытого суперудара.
   - Открытие сохраняет текущий `ActiveSuperAttackId`.
