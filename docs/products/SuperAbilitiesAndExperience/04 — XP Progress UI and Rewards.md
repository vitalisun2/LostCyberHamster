# 04 — XP Progress UI and Rewards

## 1. Целевое поведение

Игрок всегда видит текущий `Player Level`, заполнение XP-шкалы и награду за завершённый забег.

### XP-панель главного меню

- Верхний HUD занимает одну компактную высоту.
- Слева находятся `DEF`, монеты и кристаллы.
- По центру находится кликабельная XP-панель.
- Панель показывает `УР. N`, XP-bar и `текущий XP / 240`.
- `XP` показан небольшой меткой внутри бара.
- Нажатие открывает экран «Суперудары».
- Справа находится `Settings`.
- Магазин открывается отдельной нижней кнопкой `M`.

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ [DEF] [🪙 1 250] [💎 24]   [ УР. 1 | XP ████████░░░░ 170 / 240 ]   [⚙] │
└──────────────────────────────────────────────────────────────────────────────┘
```

### XP-баннер после победы

- После открытия `WinModal` сверху появляется временный XP overlay.
- Баннер показывает текущий Level, XP-bar и `текущий XP / 240`.
- `+N XP` показывает общую награду завершённого забега.
- XP-полоса анимированно заполняется.
- При Level Up остаток переносится в новую шкалу.
- После анимации баннер уезжает вверх. `WinModal` остаётся открыт.

```text
          ВРЕМЕННЫЙ XP OVERLAY ПОВЕРХ WINMODAL
     +--------------------------------------------------+
     | LEVEL 1       [============--------]  220/240 XP |
     |                        +20 XP                    |
     +--------------------------------------------------+
                         ↓ заполнение

+------------------------------------------------------------+
|                         WINMODAL                           |
|                  ИГРОВОЙ УРОВЕНЬ 8                        |
|                                                            |
|                         *  *  *                            |
|                                                            |
|                    СЧЁТ: 1 250                             |
|                                                            |
|              [ HOME ] [ RETRY ] [ CONTINUE ]               |
+------------------------------------------------------------+

После анимации XP-баннер уезжает вверх. WinModal остаётся.
```

### Level Up Modal

Игрок выбирает `Home`, `Retry` или `Continue` в `WinModal`. При новом Player Level действие сохраняется, `WinModal` закрывается, затем открывается отдельная `Level Up Modal`.

```text
+------------------------------------------------------------+
|                       LEVEL UP!                            |
|                                                            |
|                     УРОВЕНЬ 1 → 2                          |
|                                                            |
|               +------------------------+                   |
|               |        [ИКОНКА]        |                   |
|               |      СУПЕРУДАР 1       |                   |
|               |                        |                   |
|               |  СУПЕРУДАР ДОСТУПЕН   |                   |
|               +------------------------+                   |
|                                                            |
|                         [ OK ]                             |
+------------------------------------------------------------+

В очереди: CONTINUE
OK закрывает модалку → выполняется CONTINUE
```

- Модалка показывает переход `УРОВЕНЬ N → N+1`.
- Карточка показывает открытый суперудар.
- Единственный CTA — `OK`.
- После `OK` выполняется выбранное ранее действие.

## 2. Текущее состояние

- `PlayerData` хранит `ExperiencePoints` и `PlayerLevel`.
- `PlayerExperienceService` применяет единый порог `240 XP` и переносит остаток.
- Главное меню уже показывает кликабельную XP-панель с Level, XP-bar и числовым прогрессом.
- XP-панель уже открывает экран «Суперудары».
- `SuperAttackService` уже определяет суперудар, открытый между двумя Player Level.
- Отдельная `Level Up Modal` уже показывает новый Level, карточку суперудара и кнопку `OK`.
- `Home`, `Retry` и `Continue` уже проходят через очередь Level Up flow.
- `WinModal` уже показывает результат забега, звёзды, score и leaderboard state.
- Итоговый XP-result объединяет уже начисленные за забег XP и хранит Player Level и XP до и после награды.
- Временный XP-баннер показывает общую награду после победы.
- Переходы из `WinModal` ждут завершения XP-баннера.

## 3. Реализованное изменение

- Все XP-награды завершённого забега собираются в один результат для UI.
- Результат содержит общую награду, XP и Player Level до начисления, XP и Player Level после начисления.
- XP-баннер показывается поверх верхней части `WinModal`.
- `+N XP` растворяется во время заполнения шкалы.
- При Level Up остаток переносится в новую шкалу.
- Завершение XP-анимации открывает готовый переход к следующему действию игрока.

## 4. Продуктовые шаги реализации

### Готово в Unity Live

1. **Постоянный прогресс в меню.**
   - Игрок видит текущий Player Level и заполнение шкалы.
   - Числовой прогресс показывает `текущий XP / 240`.
   - Нажатие на панель открывает экран «Суперудары».

2. **Переход через Level Up Modal.**
   - Выбранное в `WinModal` действие сохраняется.
   - Новый Player Level и открытый суперудар показываются в отдельной модалке.
   - `OK` закрывает модалку и выполняет сохранённое действие.
   - Если Player Level остался прежним, действие выполняется сразу.

3. **Итоговая XP-награда победного забега.**
   - Все XP, полученные по итогам победы, объединяются в одну награду `+N XP`.
   - Результат хранит состояние шкалы до и после начисления.
   - Результат фиксирует новый Player Level и признак Level Up.

4. **Награда поверх WinModal.**
   - XP-баннер появляется в верхней части экрана.
   - `+N XP` растворяется, пока шкала заполняется.
   - При достижении `240 XP` шкала начинает новый цикл с перенесённым остатком.
   - После завершения баннер уезжает вверх.

5. **Связь XP-баннера с Level Up flow.**
   - XP-баннер завершает показ награды до перехода к следующему действию игрока.
   - При повышении Player Level сохраняется существующий переход через отдельную `Level Up Modal`.
