# 02. Первое облачное сохранение после связывания гостя

## Результат

После успешного связывания гостя его текущий прогресс становится первой облачной версией без смены `PlayerId`. Зависит от задачи 01.

## Что сделать

- Добавить `CloudSyncService` поверх gateway.
- Запускать первую отправку только по факту успешного связывания гостя.
- Сначала завершить локальный commit, затем создать глубокую копию с текущим `PlayerId` и отправить её в фоне.
- После ответа сохранить серверные revision и время как текущую облачную версию.
- При ошибке сохранить локальные данные и снимок для повтора.

## Проверка

Unit-тесты через fake gateway проверяют неизменный `PlayerId`, запуск только после успешной связи и локального commit, полный снимок правильного владельца и безопасную ошибку.
