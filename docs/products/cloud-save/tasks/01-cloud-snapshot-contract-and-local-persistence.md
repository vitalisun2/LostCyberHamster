# 01. Контракт облачного снимка и UGS gateway

## Результат

Есть один формат полного облачного снимка и небольшой gateway над UGS Cloud Save. `GameDataManager` продолжает отвечать только за локальные данные.

## Что сделать

- Добавить DTO: глубокая копия полного `PlayerData`, `PlayerId`, revision, базовая revision и время сохранения.
- Добавить gateway для загрузки и условной записи целого снимка.
- Возвращать из записи подтверждённые сервером revision и время.
- Реализовать UGS-адаптер и fake через общий контракт.
- Хранить снимок одной записью UGS.

## Проверка

Unit-тесты проверяют полный round-trip, владельца, revision и независимость копии от исходного `PlayerData`. UGS-адаптер компилируется с Cloud Save `3.2.0`; fake работает без сети.
