# 07. Статус синхронизации и ручной retry

## Результат

Settings показывает компактный статус синхронизации и retry после offline или ошибки. Зависит от задачи 06.

## Что сделать

- Добавить в `CloudSyncService` read-only состояние `Saved`, `Syncing`, `Offline` или `Error`.
- Ставить `Saved`, когда облако подтвердило актуальную локальную revision и pending отсутствует.
- Ставить `Syncing` для активной операции, `Offline` для ожидающего сеть снимка, `Error` для другой ошибки.
- Подключить Account-блок Settings к состоянию сервиса.
- Retry повторяет общий sync path последнего снимка; повторные нажатия не создают параллельные операции.

## Проверка

Unit-тесты проверяют переходы четырёх состояний, отсутствие ложного `Saved`, сохранение pending после ошибки и успешный retry. Settings только отображает состояние и вызывает retry.
