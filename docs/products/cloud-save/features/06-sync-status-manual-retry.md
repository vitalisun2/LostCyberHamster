# 06. Статус синхронизации и ручной повтор

## Суть

Синхронизация работает в фоне. Settings показывает её состояние и позволяет повторить отправку после ошибки.

## Как работает

1. `Saved` — облако подтвердило актуальный снимок.
2. `Syncing` — идёт отправка.
3. `Offline` — последний снимок ждёт сеть.
4. `Error` — облачная операция завершилась другой ошибкой.
5. Для `Offline` и `Error` доступен неблокирующий retry.
6. После retry статус показывает новый фактический результат.

## Проверка

Settings верно показывает четыре состояния. После восстановления условий retry переводит актуальный снимок в `Saved`.
