# 01. Первый облачный снимок

## Что и зачем

После успешной привязки гостевого аккаунта игра впервые сохраняет в облако весь текущий прогресс одним атомарным снимком. Это превращает уже накопленный гостевой прогресс в начальное состояние привязанного аккаунта без частичного сохранения.

## Зависимости

- Успешная привязка текущего гостевого аккаунта.
- Доступен текущий UGS `PlayerId`.
- Локальный снимок всей игры готов к сохранению.

## Продуктовый алгоритм

1. Пользователь успешно привязывает текущий гостевой аккаунт.
2. Игра фиксирует локальный снимок всей игры для текущего UGS `PlayerId`.
3. Игра отправляет этот снимок в облако как первое состояние аккаунта.
4. Успешная запись подтверждает наличие облачного снимка; ошибка оставляет локальный прогресс неизменным и допускает повтор.

## Критерии приёмки

- Первая облачная запись запускается только после успешной привязки гостевого аккаунта.
- В облако попадает весь актуальный гостевой прогресс одним снимком.
- Снимок относится только к текущему UGS `PlayerId`.
- Ошибка загрузки не блокирует игру и не удаляет локальный прогресс.
- Даже после успешного первого снимка кросс-девайсное продолжение игры не обещается до реализации восстановления существующего аккаунта из feature 02.

## Граничные случаи

- Привязка не завершилась: снимок не отправляется.
- Сеть пропала после привязки: локальный прогресс остаётся источником для последующего повтора.
- Повтор после неопределённого результата записи отправляет целый актуальный снимок, а не отдельные поля.

## Вне рамок

- Вход в уже существующий аккаунт и восстановление его прогресса.
- Разрешение конфликтов между устройствами.
- Объединение гостевого и облачного прогресса.
