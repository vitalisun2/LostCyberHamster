# 01. Первый облачный снимок

## Суть

После связывания гостя весь его прогресс становится первой облачной версией. `PlayerId` остаётся прежним. Снимок хранится целиком с revision, владельцем и временем сохранения.

## Как работает

1. Игрок связывает гостя с аккаунтом.
2. Игра локально сохраняет полный `PlayerData`.
3. Из сохранённого состояния создаётся глубокая копия с текущим `PlayerId` и первой revision.
4. Копия отправляется в облако без ожидания со стороны игрока.
5. Ошибка оставляет локальный прогресс и снимок для следующей попытки.

## Проверка

После связывания `PlayerId` не изменился. В облаке лежит один полный снимок правильного владельца с revision и временем сервера.
