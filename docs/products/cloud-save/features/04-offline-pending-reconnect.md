# 04. Offline-прогресс и повторная синхронизация

## Суть

Без сети игра продолжает сохраняться локально. Последний снимок ждёт отправки, переживает перезапуск и уходит в облако после возвращения связи.

## Как работает

1. Checkpoint сохраняет прогресс локально и записывает новый pending-снимок.
2. Более свежий снимок заменяет предыдущий pending.
3. После запуска игры или возвращения сети сервис повторяет отправку.
4. Отправляется только снимок текущего `PlayerId`.
5. Pending очищается после подтверждения именно его revision.

## Проверка

Несколько offline-сохранений и перезапуск оставляют последний снимок. После возвращения сети он загружается в облако нужного аккаунта.
