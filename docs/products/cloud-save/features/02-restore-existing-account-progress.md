# 02. Восстановление существующего аккаунта

## Суть

На новом устройстве или после переустановки игрок возвращает прогресс через связанный аккаунт. Облачный снимок заменяет временного гостя после предупреждения, подтверждения и проверки данных.

## Как работает

1. Игрок выбирает вход в существующий аккаунт.
2. Игра предупреждает о замене гостевого прогресса.
3. После подтверждения игра входит в аккаунт и загружает его полный снимок.
4. Проверенный снимок целиком и атомарно сохраняется локально.
5. Ошибка загрузки или проверки оставляет гостевой прогресс без изменений.

## Проверка

Успешный вход восстанавливает весь прогресс аккаунта. Ошибка, чужой владелец или повреждённый снимок не меняют текущие данные.
