# 11. Экономика не объединяется по полям

Связано с [безопасным выбором снимка](../features/05-conflict-safe-multi-device-sync.md).

Статус: pending

## Предусловия

- Для одного UGS `PlayerId` подготовлен локальный снимок L: progression rank 10, 10 монет, только скин L.
- Облачный снимок C: progression rank 9, 1000 монет, только скин C; его revision и server time могут быть выше.

## Шаги

1. Запустить обычную синхронизацию аккаунта.
2. Дождаться разрешения конфликта и `Saved`.
3. Проверить progression rank, баланс и набор скинов в runtime, локальном и облачном состояниях.

## Ожидаемый результат и логи

Целиком побеждает L: результат содержит rank 10, 10 монет и только скин L. 1000 монет и скин C не добавляются; field-wise или аддитивного merge нет. Наблюдаемое состояние/лог категории conflict resolution подтверждает выбор одного whole snapshot без merge экономики.

## Cleanup

Восстановить исходный тестовый снимок аккаунта.

## Scope

Проверяется запрет merge валюты и скинов как представителей экономики, не все игровые поля по отдельности.
