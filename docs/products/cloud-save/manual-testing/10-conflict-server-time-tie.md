# 10. Server time разрешает оставшийся tie

Связано с [безопасным выбором снимка](../features/05-conflict-safe-multi-device-sync.md).

Статус: pending

## Предусловия

- Для одного UGS `PlayerId` локальный снимок L и облачный снимок C имеют одинаковые progression rank и revision.
- У C позднее server time; выполняется обычная синхронизация.

## Шаги

1. Записать контрольные значения и server time обоих снимков.
2. Запустить обычную синхронизацию аккаунта.
3. Дождаться разрешения конфликта и `Saved`.
4. Сверить runtime, локальный и облачный снимки.

## Ожидаемый результат и логи

Целиком побеждает C с более поздним server time. Наблюдаемое состояние/лог категории conflict resolution показывает равенство первых двух критериев и server time как tie-breaker.

## Cleanup

Восстановить исходные локальный и облачный тестовые снимки.

## Scope

Проверяется третий критерий; случай полного равенства всех трёх значений не покрывается.
