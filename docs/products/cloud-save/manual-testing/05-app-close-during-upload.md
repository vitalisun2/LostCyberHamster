# 05. Закрытие приложения во время upload

Связано с [автоматической синхронизацией](../features/03-automatic-checkpoint-sync.md) и [durable pending](../features/04-offline-pending-reconnect.md).

Статус: pending

## Предусловия

- Привязанный аккаунт находится в состоянии `Saved`.
- Cloud upload можно замедлить, чтобы приложение успело показать `Syncing`.

## Шаги

1. Выполнить поддерживаемую контрольную точку с заметным изменением прогресса.
2. После локального сохранения и появления `Syncing` закрыть приложение до подтверждения upload.
3. Запустить приложение без сети.
4. Проверить локальное состояние и статус синхронизации.

## Ожидаемый результат и логи

Изменение целиком восстановлено из локального снимка. При отсутствии подтверждённого upload оно остаётся pending, UI показывает `Offline`, а наблюдаемое состояние/лог категории cloud save не заявляет ложный `Saved`.

## Cleanup

Вернуть сеть, дождаться успешной синхронизации и восстановить исходный тестовый снимок.

## Scope

Проверяется закрытие после локального save; принудительное завершение во время самого локального save не покрывается.
