# 07. Reconnect отправляет pending-снимок

Связано с [офлайн-изменениями](../features/04-offline-pending-reconnect.md).

Статус: pending

## Предусловия

- Для текущего UGS `PlayerId` есть durable pending-снимок с известными значениями.
- UI показывает `Offline`, сеть отключена.

## Шаги

1. Включить сеть, не выполняя новую контрольную точку.
2. Продолжить обычное взаимодействие с игрой во время синхронизации.
3. Дождаться `Saved`.
4. Сверить облачный снимок с самым новым pending-снимком.

## Ожидаемый результат и логи

Игра неблокирующе переходит через `Syncing` в `Saved`; в облако отправлен весь самый новый pending-снимок для правильного `PlayerId`. Наблюдаемое состояние/лог категории reconnect sync подтверждает успешную запись и снятие pending-признака.

## Cleanup

Восстановить исходный тестовый снимок аккаунта.

## Scope

Проверяется reconnect без конкурирующего более нового cloud snapshot.
