# 02. Облако существующего аккаунта заменяет гостя

Связано с [восстановлением существующего аккаунта](../features/02-restore-existing-account-progress.md).

Статус: pending

## Предусловия

- Существующий аккаунт A имеет целый облачный снимок с известными значениями прогресса, валюты и скинов.
- На устройстве активен гость B с заведомо другими значениями.

## Шаги

1. Записать все контрольные значения гостя B.
2. Явно войти в существующий аккаунт A.
3. Дождаться завершения cloud download и проверить runtime-состояние игры.
4. Перезапустить игру и повторно проверить состояние аккаунта A.

## Ожидаемый результат и логи

Целый снимок A полностью заменяет гостя B. Ни одно значение B не сохраняется, не загружается и не объединяется с A; гостевой снимок B отброшен. Наблюдаемое состояние/лог категории восстановления показывает успешное применение целого cloud snapshot для `PlayerId` аккаунта A.

## Cleanup

Выйти из тестового аккаунта A и очистить локальные тестовые данные.

## Scope

Проверяется только явный успешный вход; обычный конфликт двух устройств не покрывается.
