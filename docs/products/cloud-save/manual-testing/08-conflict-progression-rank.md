# 08. Конфликт решается по progression rank

Связано с [безопасным выбором снимка](../features/05-conflict-safe-multi-device-sync.md).

Статус: pending

## Предусловия

- Для одного UGS `PlayerId` подготовлены локальный снимок L с более высоким рангом прогресса и облачный снимок C с более высокой ревизией и более поздним серверным временем.
- Запускается обычная синхронизация, не явный вход в существующий аккаунт.

## Шаги

1. Записать контрольные значения обоих снимков.
2. Запустить обычную синхронизацию аккаунта.
3. Дождаться разрешения конфликта и `Saved`.
4. Сверить runtime, локальный и облачный снимки.

## Ожидаемый результат и логи

Побеждает целый снимок L только из-за более высокого progression rank; поздние время и ревизия C не меняют выбор. Наблюдаемое состояние/лог категории conflict resolution указывает progression rank как решающий критерий и применение одного целого снимка.

## Cleanup

Восстановить исходный облачный снимок тестового аккаунта.

## Scope

Проверяется первый критерий обычного same-account конфликта; явный existing sign-in не покрывается.
