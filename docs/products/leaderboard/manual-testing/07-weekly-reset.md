# Еженедельный сброс Leaderboard

## Предусловия

- Используется тестовый Leaderboard со сбросом в пределах тестового окна.
- В нём опубликован результат текущего игрока.

## Шаги

1. Зафиксировать текущую версию Leaderboard и результат игрока.
2. Дождаться настроенного времени сброса.
3. Повторно запросить Leaderboard и результат игрока.
4. Опубликовать первый результат нового периода.

## Ожидаемый результат и логи

- После сброса активна новая версия без результатов предыдущей недели.
- Первый новый результат рассчитывается без старых `LevelBestScore`.
- Console и Unity Dashboard показывают новый период.

## Cleanup/reset

- Вернуть штатное расписание тестового Leaderboard.

## Scope / не покрывает

- Не проверяет архив предыдущей недели.
