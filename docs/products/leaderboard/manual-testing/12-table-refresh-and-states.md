# Обновление и состояния таблицы

## Предусловия

- Доступны заполненный и пустой Leaderboards.
- Соединение с сетью можно временно отключить.

## Шаги

1. Открыть заполненный Leaderboard.
2. Переключить часть дня в этой же локации и проверить новые строки.
3. Выбрать другую локацию и проверить её таблицу.
4. Открыть пустой Leaderboard.
5. Отключить сеть и запросить другую таблицу.
6. Восстановить сеть и повторить запрос.

## Ожидаемый результат и логи

- При каждом запросе отображается состояние загрузки.
- Смена части дня и смена локации заменяют строки данными соответствующего Leaderboard.
- Пустой Leaderboard показывает пустое состояние без старых строк.
- Ошибка сети отображается явно; после восстановления повторный запрос успешен.

## Cleanup/reset

- Восстановить соединение с сетью.

## Scope / не покрывает

- Не проверяет длительные серверные сбои.
