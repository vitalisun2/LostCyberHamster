# Экран результата при улучшении

## Предусловия

- `LevelBestScore` текущего уровня равен `30`.
- `PartOfDayTotalScore` равен `77`.

## Шаги

1. Успешно завершить уровень с `RunScore = 35`.
2. Открыть экран результата.
3. Сверить показанные значения с Unity Leaderboards.

## Ожидаемый результат и логи

- Экран показывает `RunScore = 35`.
- Рекорд уровня показан как `30 → 35`.
- Общий результат показан как `77 → 82`.
- Unity Leaderboards содержит новые значения.

## Cleanup/reset

- Восстановить исходное тестовое состояние.

## Scope / не покрывает

- Не проверяет забег без улучшения.
