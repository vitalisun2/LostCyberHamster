# Сброс Run Score

## Предусловия

- В текущем забеге набрано больше `0` очков.

## Шаги

1. Завершить или перезапустить текущий уровень.
2. Начать новый забег.

## Ожидаемый результат и логи

- Новый забег начинается с `RunScore = 0`.
- Очки предыдущего забега не переносятся.

## Cleanup/reset

- Не требуется.

## Scope / не покрывает

- Не проверяет недельные рекорды.
