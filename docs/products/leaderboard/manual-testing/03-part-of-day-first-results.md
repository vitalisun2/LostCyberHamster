# Первые результаты части дня

## Предусловия

- Для выбранной части дня нет результатов текущей недели.
- В части дня есть три уровня.

## Шаги

1. Успешно завершить первый уровень с `RunScore = 30`.
2. Успешно завершить второй уровень с `RunScore = 47`.
3. Не проходить третий уровень.

## Ожидаемый результат и логи

- `LevelBestScore` равны `30`, `47` и `0`.
- `PartOfDayTotalScore` равен `77`.
- Console показывает обновление соответствующих уровней и суммы.

## Cleanup/reset

- Очистить тестовое недельное состояние.

## Scope / не покрывает

- Не проверяет повторные прохождения.
