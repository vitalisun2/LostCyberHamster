# Улучшение и сохранение рекорда уровня

## Предусловия

- Лучшие результаты двух уровней равны `30` и `47`; `PartOfDayTotalScore = 77`.

## Шаги

1. Повторно пройти первый уровень с `RunScore = 35`.
2. Ещё раз пройти первый уровень с `RunScore = 25`.

## Ожидаемый результат и логи

- После первого прохождения рекорд первого уровня равен `35`, общая сумма — `82`.
- После второго прохождения рекорд и сумма не меняются.
- Console явно показывает улучшение и игнорирование худшего результата.

## Cleanup/reset

- Очистить тестовое недельное состояние.

## Scope / не покрывает

- Не проверяет Unity Leaderboards.
