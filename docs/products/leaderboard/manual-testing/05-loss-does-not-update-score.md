# Поражение не обновляет недельный результат

## Предусловия

- Зафиксированы текущие `LevelBestScore` и `PartOfDayTotalScore`.

## Шаги

1. Начать уровень и набрать результат выше его текущего рекорда.
2. Проиграть до успешного завершения уровня.
3. Повторно запросить состояние рейтинга.

## Ожидаемый результат и логи

- `RunScore` проигранного забега не становится новым рекордом.
- `LevelBestScore` и `PartOfDayTotalScore` остаются прежними.
- В Unity Leaderboards не отправляется обновление.

## Cleanup/reset

- Не требуется.

## Scope / не покрывает

- Не проверяет экран поражения.
