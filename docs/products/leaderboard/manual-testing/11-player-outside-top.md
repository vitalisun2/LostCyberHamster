# Позиция игрока вне загруженного топа

## Предусловия

- Leaderboard содержит больше `N` записей.
- Позиция текущего игрока ниже `N`.

## Шаги

1. Открыть Leaderboard.
2. Просмотреть загруженный топ и закреплённую строку игрока.

## Ожидаемый результат и логи

- Таблица показывает верхние `N` записей.
- Позиция текущего игрока показана отдельной закреплённой строкой.
- Место, имя и score игрока совпадают с Unity Leaderboards.

## Cleanup/reset

- Не требуется.

## Scope / не покрывает

- Не определяет окончательное значение `N`.
