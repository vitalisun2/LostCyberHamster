# Отображение таблицы результатов

## Предусловия

- Выбранный Leaderboard содержит несколько известных записей.
- Текущий игрок входит в загружаемый топ `N`.

## Шаги

1. Открыть выбранный Leaderboard.
2. Сравнить строки таблицы с данными Unity Leaderboards.
3. Найти строку текущего игрока.

## Ожидаемый результат и логи

- Строки отсортированы по месту.
- Место, публичное имя и score каждой строки совпадают с ответом Unity.
- Строка текущего игрока выделена.

## Cleanup/reset

- Не требуется.

## Scope / не покрывает

- Не проверяет позицию игрока за пределами топа.
