# Начисление Run Score

## Предусловия

- Запущен контролируемый уровень с монетой, бонусами энергии, кристалла и жизни, а также уничтожаемым препятствием.
- В Console видны сообщения `Run Score`.

## Шаги

1. Начать уровень.
2. Последовательно собрать монету, энергию, кристалл и жизнь.
3. Уничтожить одно препятствие и успешно завершить уровень.

## Ожидаемый результат и логи

- Начальное значение равно `0`.
- Значения последовательно становятся `1`, `3`, `5`, `7` и `10`.
- Итоговый `RunScore` равен `10`; каждое событие отражено в Console один раз.

## Cleanup/reset

- Перезапустить уровень.

## Scope / не покрывает

- Не проверяет сохранение результата и UI.
