# Отображение Run Score в HUD

## Предусловия

- Запущен уровень с известными источниками очков.
- В Console видны сообщения `Run Score`.

## Шаги

1. Проверить значение HUD при старте.
2. Собрать монету и бонус, затем уничтожить препятствие.
3. Перезапустить уровень.

## Ожидаемый результат и логи

- HUD начинает с `0` и последовательно показывает `1`, `3` и `6`.
- Значения совпадают с Console.
- После перезапуска HUD снова показывает `0`.

## Cleanup/reset

- Не требуется.

## Scope / не покрывает

- Не проверяет изменение интерфейса жизней и ресурсов.
