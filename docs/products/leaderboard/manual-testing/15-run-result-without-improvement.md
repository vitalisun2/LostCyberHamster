# Экран результата без улучшения

## Предусловия

- `LevelBestScore` текущего уровня равен `35`.
- `PartOfDayTotalScore` равен `82`.

## Шаги

1. Успешно завершить уровень с `RunScore = 25`.
2. Открыть экран результата.
3. Сверить показанные значения с Unity Leaderboards.

## Ожидаемый результат и логи

- Экран показывает `RunScore = 25`.
- Рекорд уровня показан как `35 → 35`, общий результат — как `82 → 82`.
- UI явно показывает отсутствие улучшения.
- Сохранённые значения Unity Leaderboards остаются без изменений.

## Cleanup/reset

- Не требуется.

## Scope / не покрывает

- Поражение проверяется отдельным сценарием.
