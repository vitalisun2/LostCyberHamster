# Навигация по рейтингам

## Предусловия

- Открыто несколько локаций; минимум одна следующая локация закрыта.
- В Console виден идентификатор запрошенного Leaderboard.

## Шаги

1. В главном меню нажать «Рейтинги».
2. Проверить список локаций и выбрать первую открытую локацию.
3. Последовательно переключить «Утро», «День», «Вечер» и «Ночь».
4. Вернуться к выбору, открыть вторую локацию и повторить переключение вкладок.

## Ожидаемый результат и логи

- В списке присутствуют только открытые локации.
- Каждая проверенная пара запрашивает свой Leaderboard.
- Идентификатор и полученные в Console данные соответствуют выбранной локации и части дня.

## Cleanup/reset

- Не требуется.

## Scope / не покрывает

- Не проверяет строки таблицы.
