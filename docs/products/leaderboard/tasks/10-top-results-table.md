# 10 — Таблица верхних результатов

**Связи:** [Feature 06 — Leaderboard Results Table](../features/06-leaderboard-results-table.md); [отображение таблицы](../manual-testing/10-results-table.md).

## Цель

Показать верхние `N` результатов выбранного Leaderboard.

## Опора / зависимости

- Экран и запросы задач 05 и 09.
- Перед реализацией требуется согласовать окончательное значение `N`.

## Реализовать

- Отрисовать строки в порядке места из ответа Unity Leaderboards.
- Для каждой строки показать место, публичное имя и `PartOfDayTotalScore`.
- Полностью заменять содержимое при смене локации или части дня.

## Проверка

- Выполнить связанный сценарий и сверить каждую видимую строку с ответом Unity Leaderboards.

## Не входит

- Отдельная позиция текущего игрока, loading/empty/error состояния и пагинация.
- Если создание строк смешивается с сетевым запросом, согласовать минимальное разделение загрузки данных и представления.
