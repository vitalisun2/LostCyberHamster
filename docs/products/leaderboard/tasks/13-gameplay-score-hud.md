# 13 — Run Score в игровом HUD

**Связи:** [Feature 07 — Gameplay Score HUD](../features/07-gameplay-score-hud.md); [отображение Run Score](../manual-testing/13-gameplay-score-hud.md).

## Цель

Показывать игроку текущий `RunScore` непосредственно во время забега.

## Опора / зависимости

- Счётчик и уведомления об изменении `RunScore` из задачи 01.
- Существующий игровой HUD.

## Реализовать

- Показать `0` при старте забега.
- Обновлять значение после каждого изменения `RunScore`.
- Сбрасывать отображение вместе со счётчиком при новом забеге.

## Проверка

- Выполнить связанный сценарий и сверить HUD с Console на каждом начислении и после перезапуска.

## Не входит

- Переработка отображения жизней, монет, кристаллов и остального HUD.
- Не добавлять второй источник состояния; HUD только отображает готовый `RunScore`.
