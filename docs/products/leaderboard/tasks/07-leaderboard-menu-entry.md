# 07 — Вход в рейтинги из главного меню

**Связи:** [Feature 05 — Leaderboard Navigation UI](../features/05-leaderboard-navigation-ui.md); [навигация по рейтингам](../manual-testing/09-leaderboard-navigation.md).

## Цель

Дать игроку отдельную точку входа в продукт Leaderboard.

## Опора / зависимости

- Существующие главное меню, UI-навигация и визуальные компоненты проекта.

## Реализовать

- Добавить кнопку «Рейтинги» в главное меню в текущем стиле.
- Использовать существующий механизм UI-навигации без добавления нового поведения возврата.
- Не добавлять данные таблицы; экран может содержать только заголовок до следующей задачи.

## Проверка

- Открыть экран кнопкой и убедиться, что существующий путь возврата продолжает работать.

## Не входит

- Выбор локации, вкладки частей дня и таблица результатов.
- Не создавать новую UI-архитектуру; при несовместимости с текущей навигацией остановиться и согласовать минимальное расширение.
