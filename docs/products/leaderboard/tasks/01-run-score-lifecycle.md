# 01 — Подсчёт Run Score

**Связи:** [Feature 01 — Run Score](../features/01-run-score.md); [начисление очков](../manual-testing/01-run-score-accrual.md), [сброс очков](../manual-testing/02-run-score-reset.md).

## Цель

Добавить законченный и проверяемый подсчёт очков одного забега.

## Опора / зависимости

- Существующие события сбора ресурсов, уничтожения препятствия, старта и завершения уровня.

## Реализовать

- Сбрасывать `RunScore` в `0` при старте каждого забега.
- Начислять `+1` за монету, `+2` за энергию, кристалл или жизнь и `+3` за уничтоженное препятствие.
- Учитывать каждое игровое событие один раз и фиксировать итог только при победе.
- Выводить изменение и итог `RunScore` в Console.

## Проверка

- Выполнить связанные ручные сценарии и сверить последовательность значений в Console.

## Не входит

- Недельные рекорды, серверное сохранение и UI.
- Упреждающий рефакторинг; при фактическом смешении ответственности или дублировании остановиться и согласовать минимальное выделение кода.
