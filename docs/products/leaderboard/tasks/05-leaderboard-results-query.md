# 05 — Получение результатов Leaderboard

**Связи:** [Feature 03 — Unity Leaderboards Integration](../features/03-unity-leaderboards-integration.md); [публикация и сохранение](../manual-testing/06-unity-publication-routing-persistence.md).

## Цель

Получать данные рейтинга, необходимые будущему экрану таблицы.

## Опора / зависимости

- Настроенные Leaderboards из задачи 03 и их идентификаторы.

## Реализовать

- Запрашивать верхние `N` записей указанного Leaderboard.
- Отдельно запрашивать позицию текущего игрока.
- Возвращать место, публичное имя и score без UI-зависимостей.
- Временно выводить ответ в Console для проверки.

## Проверка

- Сверить порядок, значения и позицию игрока в Console с Unity Dashboard.

## Не входит

- Отрисовка таблицы и окончательный выбор `N`.
- Не вводить DTO или дополнительный слой заранее; выделить их только при фактическом росте параметров или повторении преобразований и после требуемого approval.
