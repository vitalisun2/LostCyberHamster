# 08 — Выбор открытой локации

**Связи:** [Feature 05 — Leaderboard Navigation UI](../features/05-leaderboard-navigation-ui.md); [навигация по рейтингам](../manual-testing/09-leaderboard-navigation.md).

## Цель

Позволить игроку выбрать локацию, для которой будет открыт рейтинг.

## Опора / зависимости

- Экран входа из задачи 07 и существующие данные об открытых локациях.

## Реализовать

- Показать на экране рейтингов только доступные игроку локации.
- Передать идентификатор выбранной локации следующему экрану.
- Исключить выбор закрытой локации и использовать существующий механизм навигации без добавления новых действий.

## Проверка

- При наличии открытых и закрытой локаций убедиться, что выбрать можно только открытые и передаётся правильный идентификатор.

## Не входит

- Вкладки частей дня и таблица результатов.
- Если фильтрация открытых локаций уже существует, переиспользовать её; дублирующую логику не добавлять.
