# 03 — Конфигурация Unity Leaderboards

**Связи:** [Feature 03 — Unity Leaderboards Integration](../features/03-unity-leaderboards-integration.md); [маршрутизация результата](../manual-testing/06-unity-publication-routing-persistence.md), [еженедельный сброс](../manual-testing/07-weekly-reset.md).

## Цель

Подготовить серверные таблицы, в которые смогут публиковаться недельные результаты.

## Опора / зависимости

- Согласованная матрица «локация + часть дня» и окружение Unity Services.

## Реализовать

- Создать отдельный Leaderboard для каждой поддерживаемой пары «локация + часть дня».
- Настроить сортировку по убыванию score и автоматический еженедельный сброс.
- Зафиксировать идентификаторы таблиц в одном существующем месте конфигурации проекта.
- Для проверки временно настроить отдельную таблицу со сбросом в доступном тестовом окне.

## Проверка

- В Unity Dashboard проверить наличие таблиц, их идентификаторы, сортировку и переход на новую версию после тестового сброса.

## Не входит

- Клиентская публикация, чтение результатов и UI.
- Новая система конфигурации не создаётся; если существующего механизма недостаточно, требуется отдельное предложение и approval.
