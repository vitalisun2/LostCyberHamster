# 09 — Выбор части дня

**Связи:** [Feature 05 — Leaderboard Navigation UI](../features/05-leaderboard-navigation-ui.md); [навигация по рейтингам](../manual-testing/09-leaderboard-navigation.md).

## Цель

Связать выбранную локацию и вкладку части дня с конкретным Unity Leaderboard.

## Опора / зависимости

- Задачи 05 и 08, а также конфигурация идентификаторов Leaderboard.

## Реализовать

- После выбора локации открыть экран с вкладками «Утро», «День», «Вечер» и «Ночь».
- При смене вкладки определить правильный Leaderboard и выполнить запрос задачи 05.
- До реализации таблицы показывать выбранную пару на экране, а ответ — в Console.

## Проверка

- Переключить все вкладки для нескольких локаций и сверить запрашиваемые идентификаторы в Console.

## Не входит

- Строки таблицы и состояния загрузки.
- Маппинг не должен дублироваться с задачей 03; при обнаружении дубля согласовать один минимальный источник конфигурации.
