# 14 — Результат забега

**Связи:** [Feature 08 — Run Result UI](../features/08-run-result-ui.md); [результат с улучшением](../manual-testing/14-run-result-improvement.md), [результат без улучшения](../manual-testing/15-run-result-without-improvement.md).

## Цель

Показать, как успешный забег повлиял на недельный рекорд уровня и части дня.

## Опора / зависимости

- Итог `RunScore`, прежнее и новое состояние публикации из задач 02 и 04.
- Существующий экран успешного завершения уровня.

## Реализовать

- После победы показать итоговый `RunScore`.
- При улучшении показать переходы старого `LevelBestScore` и `PartOfDayTotalScore` к новым значениям.
- Без улучшения показать неизменные рекорды и явно обозначить отсутствие нового рекорда.
- Использовать подтверждённый результат серверного обновления, не пересчитывать его повторно в UI.

## Проверка

- Выполнить оба связанных сценария и сверить значения экрана с Unity Leaderboards.

## Не входит

- Экран поражения, анимации рекорда, награды и изменение основного flow завершения уровня.
- Если в UI приходится передавать разрозненный набор значений, остановиться и согласовать минимальный result DTO.
