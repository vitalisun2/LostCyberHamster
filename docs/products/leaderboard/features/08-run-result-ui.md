# 08 — Run Result UI

**Что:** показ влияния завершённого забега на недельные результаты.

**Задача:** объяснить игроку, улучшил ли забег его рекорд и общий результат части дня.

**Алгоритм:**

1. После победы показать итоговый `RunScore`.
2. Показать предыдущий и новый `LevelBestScore`.
3. Показать предыдущий и новый `PartOfDayTotalScore`.
4. При отсутствии улучшения оставить рекорды без изменений; поражение не публиковать.

**Проверка:** значения на экране должны совпадать с состоянием, сохранённым в Unity Leaderboards.
