# 04 — Player Display Name

**Что:** автоматически создаваемый публичный псевдоним игрока.

**Задача:** показывать понятное имя при мягкой авторизации, не раскрывая Player ID и не требуя ручного ввода.

**Алгоритм:**

1. После авторизации проверить наличие сохранённого имени.
2. При отсутствии создать имя из безопасных списков прилагательных и существительных с цифровым суффиксом, например `NeonHamster-4821`.
3. Сохранить имя в серверном профиле и использовать его в Unity Leaderboards.
4. Не менять автоматически уже созданное имя.

**Проверка:** новый гость получает стабильный псевдоним, который возвращается в его записи Leaderboard после повторного входа.
