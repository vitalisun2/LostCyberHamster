# 07 — Gameplay Score HUD

**Что:** отображение `RunScore` во время текущего забега.

**Задача:** сразу показывать игроку влияние его действий на результат прохождения.

**Алгоритм:**

1. При старте показать `0`.
2. Обновлять значение после каждого изменения `RunScore`.
3. При новом забеге сбрасывать значение вместе со счётчиком.

**Проверка:** значение HUD должно совпадать с начислениями `Run Score` в Console.
