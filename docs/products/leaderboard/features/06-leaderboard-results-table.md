# 06 — Leaderboard Results Table

**Что:** таблица результатов выбранного Leaderboard.

**Задача:** показать игроку лидеров и его собственную позицию.

**Алгоритм:**

1. Получить верхние `N` записей выбранного Leaderboard.
2. Показать место, публичное имя и `PartOfDayTotalScore` каждой записи.
3. Выделить строку текущего игрока.
4. Если игрок не входит в топ, показать его отдельной закреплённой строкой.
5. Обновлять таблицу при смене локации или части дня и обрабатывать загрузку, пустой результат и ошибку.

**Проверка:** сверить показанные строки с ответом Unity Leaderboards и проверить переключение вкладок; значение `N` выбрать перед реализацией.
