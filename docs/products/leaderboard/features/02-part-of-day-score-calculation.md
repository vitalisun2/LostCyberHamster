# 02 — Part-of-Day Score Calculation

**Что:** расчёт лучшего недельного результата каждого уровня и их суммы для части дня.

**Задача:** получить единый `PartOfDayTotalScore` для нескольких уровней одной части дня.

**Алгоритм:**

1. После победы сравнить `RunScore` с `LevelBestScore` текущего уровня.
2. Заменить рекорд только при улучшении.
3. Для непройденного за неделю уровня использовать `0`.
4. Рассчитать `PartOfDayTotalScore` как сумму всех `LevelBestScore` части дня.

**Проверка:** вывести старые и новые рекорды в Console; худший повторный забег не должен менять сумму.
