# 05 — Leaderboard Navigation UI

**Что:** вход в рейтинги и выбор конкретной таблицы.

**Задача:** позволить игроку выбрать открытую локацию и часть дня.

**Алгоритм:**

1. Добавить в главное меню кнопку «Рейтинги».
2. Показать экран выбора только открытых локаций.
3. После выбора открыть экран с вкладками «Утро», «День», «Вечер», «Ночь».
4. По выбранной вкладке определить Leaderboard и запросить его данные.
5. До появления таблицы выводить выбранный Leaderboard и полученные данные в Console.

**Проверка:** пройти все переходы и убедиться, что каждая вкладка запрашивает правильный Leaderboard.
