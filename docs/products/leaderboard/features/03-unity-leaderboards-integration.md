# 03 — Unity Leaderboards Integration

**Что:** хранение и получение рейтингов через Unity Leaderboards.

**Задача:** публиковать общие недельные результаты игроков без собственной базы и механизма ранжирования.

**Алгоритм:**

1. Использовать отдельный Leaderboard для каждой пары «локация + часть дня».
2. Хранить `PartOfDayTotalScore` как score, а `LevelBestScore` уровней — как служебные данные записи.
3. После победы загрузить состояние игрока, пересчитать его и опубликовать обновление.
4. Получать топ игроков и отдельную позицию текущего игрока.
5. Настроить автоматический еженедельный сброс средствами Unity Leaderboards.

**Проверка:** публиковать и читать результаты через Console и сверять их с данными Unity Dashboard.
