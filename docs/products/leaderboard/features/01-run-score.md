# 01 — Run Score

**Что:** подсчёт очков текущего забега.

**Задача:** создать измеримый результат прохождения уровня для последующих функций лидерборда.

**Алгоритм:**

1. При старте `RunScore = 0`.
2. Монета даёт `+1`, любой бонус — `+2`, уничтоженное препятствие — `+3`.
3. Каждое событие учитывается один раз.
4. При победе итог фиксируется; при поражении не применяется к рейтингу.

**Проверка:** вывести начисления и итоговый `RunScore` в Console и сверить их с игровыми событиями.
