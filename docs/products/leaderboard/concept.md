# Leaderboard

## Этап 1 — Research

### Общий концепт

**Leaderboard** — система еженедельного соревнования, в которой игроки набирают очки при прохождении уровней. Результат каждой части дня рассчитывается как сумма лучших результатов всех её уровней за неделю и сравнивается с результатами других игроков.

### Фичи продукта

1. **Run Score** — подсчёт очков текущего забега: `+1` за монету, `+2` за любой бонус и `+3` за уничтоженное препятствие.
2. **Part-of-Day Score Calculation** — сохранение лучшего результата каждого уровня и расчёт `PartOfDayTotalScore` как их суммы.
3. **Unity Leaderboards Integration** — публикация и получение результатов, а также настройка автоматического еженедельного сброса.
4. **Player Display Name** — автоматическое создание и сохранение публичного псевдонима игрока.
5. **Leaderboard Navigation UI** — вход через кнопку «Рейтинги», выбор открытой локации и переключение частей дня.
6. **Leaderboard Results Table** — отображение топа игроков и отдельной позиции текущего игрока.
7. **Gameplay Score HUD** — отображение очков текущего забега во время игры.
8. **Run Result UI** — показ результата забега, обновления рекорда уровня и изменения общего результата части дня.

## UI-флоу рейтингов

В продукте используются два экрана рейтингов:

1. Выбор открытой локации.
2. Таблица рейтинга выбранной локации и части дня.

Основной вход расположен в главном меню. После завершения последнего уровня части дня на итоговом экране появляется кнопка «Рейтинг», которая сразу открывает таблицу текущей локации и завершённой части дня. Таблица не открывается принудительно.

После обычной победы результат отправляется в фоне, но рейтинг не показывается. После поражения результат не отправляется и рейтинг не показывается.

```text
+-----------------+     +------------------+     +--------------------+
| Главное меню    |     | Выбор локации    |     | Таблица рейтинга   |
|                 |     |                  |     |                    |
| [ Рейтинги ] ---+---->| New York         +---->| Локация            |
|                 |     | Paris            |     | Часть дня          |
+-----------------+     | Barcelona        |     | Топ-50             |
                        +------------------+     +--------------------+
                                                          ^
+----------------------------+                            |
| Часть дня завершена        |                            |
|                            |                            |
| Итог: 9 450                |                            |
| [ Продолжить ] [ Рейтинг ] +----------------------------+
+----------------------------+
```

Если игроку доступна только одна локация, экран выбора локации пропускается.

### Смена имени в SettingsModal

При первом входе Unity Player Names создаёт имя через `GetPlayerNameAsync`. Игрок может изменить его в существующей `SettingsModal`.

`SettingsModal` сохраняет фиксированный размер `1280x720`:

- тело настроек — вертикальный `ScrollView`;
- footer с кнопками «Отмена» и «Сохранить» всегда остаётся на месте;
- строка имени располагается сразу после строки аккаунта;
- нижняя кнопка «Сохранить» не отвечает за имя.

Обычное состояние показывает полное Unity-имя с `#suffix` и кнопку «Изменить»:

```text
+------------------------------------------------------------------+
|                         НАСТРОЙКИ                                |
| +--------------------------------------------------------------+ |
| |                         SCROLLVIEW                           | |
| | Язык           Русский                                      | |
| | Музыка         Включена                                     | |
| | Звук           Включён                                      | |
| | Аккаунт        Подключён                                    | |
| | Имя            NeonHamster#4821              [ ИЗМЕНИТЬ ]   | |
| | Облако         Сохранено                                    | |
| | Версия         1.0.0                                        | |
| +--------------------------------------------------------------+ |
|                                                                  |
|                         [ ОТМЕНА ] [ СОХРАНИТЬ ]                  |
+------------------------------------------------------------------+
```

После «Изменить» строка переходит в edit state. В input показывается базовая часть без `#suffix`:

```text
+------------------------------------------------------------------+
| Имя       [ NeonHamster________ ] [ ОТМЕНА ] [ СОХРАНИТЬ ]      |
+------------------------------------------------------------------+
```

Кнопка «Сохранить» в строке имени сразу вызывает Unity `UpdatePlayerNameAsync`. Допустимо `3–16` символов без пробелов. Во время запроса input и кнопки заблокированы, кнопка показывает loading. При успехе строка возвращается в обычное состояние с полным именем из ответа Unity. При ошибке edit state и введённое значение сохраняются, рядом показывается ошибка и доступен повтор.

### Интеграция с WinModal

Для результата забега используется существующая `WinModal`. Новая модалка не создаётся. Блок результата размещается между звёздами и нижним рядом кнопок.

```text
+----------------------------------------------------------+
|                         NEW YORK                         |
|                          УРОВЕНЬ 5                       |
|                                                          |
|                      *     *     *                       |
|                                                          |
|              +----------------------------+              |
|              |    ОЧКИ ЗА ЗАБЕГ: 1 250    |              |
|              |    НОВЫЙ РЕКОРД УРОВНЯ!    |              |
|              |    ИТОГ УТРА: 9 450        |              |
|              +----------------------------+              |
|                                                          |
|                   [ РЕЙТИНГ УТРА ]                       |
|                                                          |
|              ( ДОМОЙ ) ( ЕЩЁ РАЗ ) ( ДАЛЬШЕ )            |
+----------------------------------------------------------+
```

После обычной победы показывается только блок результата. Если рекорд уровня улучшен:

```text
ОЧКИ ЗА ЗАБЕГ: 1 250
НОВЫЙ РЕКОРД УРОВНЯ!
ИТОГ УТРА: 9 450
```

Если рекорд не улучшен:

```text
ОЧКИ ЗА ЗАБЕГ: 980
РЕКОРД УРОВНЯ: 1 250
```

Кнопка «Рейтинг утра» показывается только после завершения последнего уровня части дня. Она открывает таблицу текущей локации сразу на вкладке завершённой части дня.

Кнопка рейтинга является широкой вторичной кнопкой. Она не добавляется четвёртой круглой кнопкой в нижний ряд, где остаются основные действия «Домой», «Ещё раз» и «Дальше».

Текст «Рейтинг обновлён» показывается только после успешной отправки результата на сервер. Локальный текст «Новый рекорд уровня» можно показать сразу после фиксации нового рекорда.

Рекомендуемые размеры для опорного разрешения `1920x1080`:

- карточка результата: ширина `560–700`, высота `120–160`;
- основной результат: `36–42 px`;
- поясняющий текст: `26–32 px`;
- кнопка рейтинга: примерно `360x88`;
- вертикальные отступы между блоками: `20–28 px`.

### Экран таблицы

На экране находятся вкладки частей дня и вертикальный список топ-50 без пагинации. Строка текущего игрока выделяется внутри списка. Если игрок находится вне топ-50, его место закрепляется отдельной строкой снизу.

```text
+------------------------------------------------------------------+
| < ЛОКАЦИИ              NEW YORK                 ЭТА НЕДЕЛЯ       |
|                                                                  |
| [ УТРО ] [ ДЕНЬ ] [ ВЕЧЕР ] [ НОЧЬ ]                             |
|                                                                  |
|  МЕСТО              ИГРОК                         ОЧКИ            |
| ---------------------------------------------------------------- |
|   1                 NeonFox                       18 420           |
|   2                 HamsterX                      17 910           |
|   3                 CyberCat                      16 840           |
|   4                 Player42                      15 120           |
|                                                                  |
|  18       >>        ВЫ                             9 450     <<    |
|  19                 RatKing                         9 310           |
|  20                 Glitch                          9 080           |
|                         |                                        |
|                         | СКРОЛЛ                                 |
|                         v                                        |
+------------------------------------------------------------------+
```

Если игрок находится вне топ-50, под списком показывается закреплённая строка:

```text
+------------------------------------------------------------------+
|                         ТОП-50                                   |
|   48                Bolt                           6 210           |
|   49                Max                            6 180           |
|   50                Byte                           6 140           |
| ---------------------------------------------------------------- |
|  ВАШЕ МЕСТО          137      ВЫ                   3 750           |
+------------------------------------------------------------------+
```

Закреплённая строка «Ваше место» показывается только тогда, когда текущего игрока нет в топ-50. Если игрок ещё не отправлял результат, вместо неё показывается сообщение «Пока нет результата».

Экран поддерживает четыре состояния: загрузка, данные, пустой рейтинг и ошибка с кнопкой «Повторить».

В первой версии не используются аватары, подиум, награды, социальные фильтры и пагинация.
