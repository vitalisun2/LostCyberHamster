# Успешная привязка гостя

**Статус:** выполнен пользователем (Passed).

## Предусловия

- Текущее состояние аккаунта — `Guest`.
- Выбранный Unity Player Account не привязан к другому UGS Player ID.
- Текущий UGS Player ID зафиксирован для сравнения.

## Шаги

1. Открыть `Settings` и нажать `ПРИВЯЗАТЬ АККАУНТ`.
2. Во время browser flow закрыть `Settings`.
3. Завершить вход через Unity Player Accounts.
4. Повторно открыть `Settings` и сравнить UGS Player ID с исходным.

## Ожидаемый результат

- Во время операции состояние меняется на `Привязываем аккаунт…`, повторное нажатие недоступно.
- Закрытие `Settings` не отменяет привязку.
- После входа показано `Аккаунт привязан`, кнопка привязки скрыта.
- UGS Player ID не изменился.
