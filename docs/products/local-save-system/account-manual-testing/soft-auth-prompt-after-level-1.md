# Мягкое предложение привязать аккаунт после уровня 1

**Статус:** не выполнен пользователем (pending).

## Предусловия

- Чистый локальный профиль, prompt ранее не показывался.
- Для основного сценария состояние аккаунта — `Guest`, устройство online.

## Шаги

1. Успешно завершить уровень 1 и после окна результата перейти в `Menu`.
2. Проверить текст prompt и нажать `ПОЗЖЕ` / `LATER`.
3. Повторно открыть `Menu` и перезапустить игру.
4. На отдельном чистом профиле повторить шаг 1 и нажать `ПРИВЯЗАТЬ` / `LINK ACCOUNT`.
5. На отдельных чистых профилях повторить завершение уровня 1 в состояниях offline и `Linked`.

## Ожидаемый результат

- В `Menu` prompt появляется один раз только для `Guest` online.
- Текст предлагает защитить доступ к игровому профилю и не обещает Cloud Save.
- `ПОЗЖЕ` / `LATER` закрывает prompt и показывает локализованную подсказку `Настройки → Аккаунт` / `Settings → Account`; повторного показа нет.
- `ПРИВЯЗАТЬ` / `LINK ACCOUNT` закрывает prompt и открывает существующий `Settings` с секцией `Account`.
- Для offline и `Linked` prompt не показывается.

## Cleanup/reset

- Восстановить сеть и удалить использованные тестовые локальные профили; сценарий не изменяет account reset-инструменты.

## Scope

- Проверяется только one-shot soft-auth prompt после уровня 1; Cloud Save, повторные напоминания и сама серверная привязка аккаунта не проверяются.
