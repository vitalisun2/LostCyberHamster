# Статус аккаунта в Settings

**Статус:** выполнен пользователем (Passed).

## Предусловия

- Гостевой аккаунт успешно определён.

## Шаги

1. Открыть `Settings`.

## Ожидаемый результат

- В секции `ACCOUNT` показано `Гость, аккаунт не привязан`.
- Кнопка `ПРИВЯЗАТЬ АККАУНТ` доступна.
- Под кнопкой нет дополнительного текста или пустого блока.
