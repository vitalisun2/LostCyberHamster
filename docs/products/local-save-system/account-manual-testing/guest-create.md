# Создание гостя

**Статус:** выполнен пользователем (Passed).

## Предусловия

- Локальная сессия Unity Authentication отсутствует.
- В Console включён фильтр `[Account]`.

## Шаги

1. Запустить игру.

## Ожидаемый результат

- Игра запускается без ожидания авторизации.
- В логах последовательно появляются `State: Resolving`, `Scenario selected: CreateGuest.` и `Guest created.`
- Итоговое состояние аккаунта — `Guest`.
