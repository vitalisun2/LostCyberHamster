# Генерация и ротация квестов

## Daily

- Локальная дата определяет активный набор.
- При первом входе за новую дату выбираются три квеста: простой, средний и сложный. Их механики различаются.
- Набор остаётся тем же до смены даты, включая перезапуск игры.
- При смене даты прошлый набор закрывается, новый выбирается из пула.
- Прогресс и награды относятся только к набору своей даты.

## Story

- Сюжетные квесты открываются по сохранённому прогрессу игрока.
- Показываются до трёх ближайших доступных и незавершённых целей.
- Выполненная цель скрывается. Её место занимает следующая доступная цель.
- Прогресс, полученный до показа цели, учитывается сразу.
- Цель сохраняет выбранную локацию, часть суток или предмет до завершения.
- Закрытая новая локация показывается без имени.
