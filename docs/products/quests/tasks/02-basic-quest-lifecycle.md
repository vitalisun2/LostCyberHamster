# 02 — Basic Quest Lifecycle

**Связи:** [концепт](../concept.md#этапы-реализации), [EditMode-проверка](../manual-testing/01-basic-quest-lifecycle-editmode.md).

## Результат

Один квест хранит состояние в `PlayerData`. Успешное перепрыгивание препятствия увеличивает прогресс. Достижение цели завершает квест.

## Сделать

1. Добавить в `PlayerData` сериализуемое состояние: `QuestId`, `CurrentProgress`, `IsCompleted`.
2. Связать состояние с определением квеста на перепрыгивание препятствий из Quest Catalog по стабильному ID.
3. Подписаться на `GameEventsManager.OnObstacleJumpedOver`. Каждое событие добавляет `1` к прогрессу.
4. На целевом значении поставить `IsCompleted`. Прогресс ограничить целью.
5. После завершения игнорировать новые события.
6. При остановке отслеживания отписаться от события.
7. Логику изменения состояния отделить от Unity-сцены.
8. Добавить `BasicQuestLifecycleTests`: начальное состояние, прогресс до цели, завершение на цели, ограничение прогресса, события после завершения.

## Ограничения

- Только один выбранный квест. KISS.
- Без универсального движка условий и иерархии обработчиков.
- Фактическое смешение ответственности или повторение логики: остановить работу, предложить рефакторинг.

## Готово, когда

Все `BasicQuestLifecycleTests` проходят по [EditMode-сценарию](../manual-testing/01-basic-quest-lifecycle-editmode.md).

## Не входит в задачу

- UI квестов.
- Получение наград.
- Генерация ежедневного набора.
- Сюжетные квесты.
- Локальное сохранение и Cloud Save.
- PlayMode и игровые сцены.
- Поддержка остальных типов условий квестов.
