# 02 — Basic Quest Lifecycle

**Связанные документы:** [концепт](../concept.md#этапы-реализации), [EditMode-проверка](../manual-testing/01-basic-quest-lifecycle-editmode.md).

## Цель

Реализовать минимальный рабочий цикл одного выбранного квеста: хранить его состояние в `PlayerData`, обновлять прогресс по событию успешного перепрыгивания препятствия и завершать квест при достижении цели.

## Реализовать

1. Добавить в `PlayerData` минимальное сериализуемое состояние выбранного квеста: `QuestId`, `CurrentProgress` и `IsCompleted`.
2. Связать состояние с одним определением квеста на перепрыгивание препятствий из готового Quest Catalog по стабильному ID.
3. Обрабатывать `GameEventsManager.OnObstacleJumpedOver`: каждое событие увеличивает прогресс на `1`.
4. При достижении целевого значения из определения квеста помечать квест завершённым и ограничивать прогресс целевым значением.
5. После завершения квеста игнорировать последующие события.
6. Обеспечить корректные подписку и отписку от игрового события.
7. Отделить изменение состояния квеста от Unity-сцены, чтобы логику можно было проверить обычными EditMode unit-тестами.
8. Добавить `BasicQuestLifecycleTests`, которые проверяют начальное состояние, прогресс до цели, завершение на цели, ограничение прогресса и отсутствие изменений после завершения.

## Принципы реализации

- Реализовать только цикл одного выбранного квеста по KISS.
- Не создавать универсальный движок условий, иерархию обработчиков или архитектуру для будущих типов квестов заранее.
- Если в ходе реализации появится фактическое смешение ответственности или повторение логики, отдельно зафиксировать необходимость рефакторинга до его выполнения.

## Проверка

Выполнить сценарий [Basic Quest Lifecycle — EditMode-проверка](../manual-testing/01-basic-quest-lifecycle-editmode.md). Все тесты `BasicQuestLifecycleTests` должны пройти.

## Не входит в задачу

- UI квестов.
- Получение наград.
- Генерация ежедневного набора.
- Сюжетные квесты.
- Локальное сохранение и Cloud Save.
- PlayMode-проверки и загрузка игровых сцен.
- Поддержка остальных типов условий квестов.
