# Basic Quest Lifecycle — EditMode-проверка

## Как проверить

1. Открыть в Unity `Window → General → Test Runner`.
2. Перейти на вкладку `EditMode`.
3. Найти и запустить набор `BasicQuestLifecycleTests`.

## Ожидаемый результат

- Все тесты проходят без исключений в Console.
- Начальный прогресс квеста равен `0`, квест не завершён.
- Каждое событие успешного перепрыгивания препятствия увеличивает прогресс на `1`.
- До достижения цели квест не завершён; при достижении цели он становится завершённым.
- После завершения дополнительные события не меняют прогресс и состояние квеста.
- Изменения отражаются в состоянии квеста внутри тестового `PlayerData`.
