# Basic Quest Lifecycle — EditMode-проверка

## Как проверить

1. Unity: `Window → General → Test Runner`.
2. Вкладка `EditMode`.
3. Запустить `BasicQuestLifecycleTests`.

## Ожидаемый результат

- Все тесты проходят. Console без исключений.
- Начало: прогресс `0`, квест не завершён.
- Успешное перепрыгивание: прогресс `+1`.
- До цели: квест активен. На цели: квест завершён.
- После завершения: прогресс и состояние не меняются.
- Состояние хранится в тестовом `PlayerData`.
