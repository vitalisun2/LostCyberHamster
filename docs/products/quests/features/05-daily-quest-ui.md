# 05 — Daily Quest UI

## Что это

Экран квестов показывает одну ежедневную цель и её состояние.

## Задача

Дать игроку понятный способ увидеть цель и текущий прогресс.

## Логика

1. Экран получает активное определение и состояние.
2. Карточка показывает локализованное название.
3. Карточка показывает текущий прогресс и цель.
4. Активное и завершённое состояния имеют разное отображение.
5. После успешного уровня карточка показывает новое значение.
6. Новая дата показывает чистое состояние ежедневного квеста.

## Проверка

Открыть экран до прогресса, после успешного уровня и после завершения. Проверить текст, счётчик и состояние карточки.
