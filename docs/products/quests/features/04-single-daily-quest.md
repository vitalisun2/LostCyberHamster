# 04 — Single Daily Quest

## Что это

Игрок получает один новый квест на каждую локальную календарную дату.

## Задача

Превратить базовый квест в ежедневную цель.

## Логика

1. `PlayerData` хранит дату активного квеста.
2. При запуске система сравнивает сохранённую дату с текущей локальной датой.
3. Совпавшая дата восстанавливает сохранённое состояние.
4. Новая дата создаёт чистое состояние квеста.
5. ID и дата сохраняются вместе с прогрессом.
6. Активный квест остаётся стабильным весь день.

## Проверка

Запустить систему дважды в одну дату и проверить сохранённый прогресс. Затем сменить дату и проверить новое состояние с прогрессом `0`.
