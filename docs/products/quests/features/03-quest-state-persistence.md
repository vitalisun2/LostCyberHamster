# 03 — Quest State Persistence

## Что это

Прогресс квеста сохраняется в данных игрока и восстанавливается после запуска игры.

## Задача

Сохранить состояние квеста между уровнями и игровыми сессиями.

## Логика

1. `PlayerData` хранит ID квеста, текущий прогресс и завершение.
2. После загрузки состояние связывается с определением по ID.
3. Успешный уровень сохраняет обновлённый прогресс.
4. Выход в меню сохраняет текущее состояние.
5. `GameDataManager` использует общий локальный и облачный путь сохранения.
6. Более новый `LastSaveDate` определяет актуальную версию `PlayerData`.

## Проверка

Получить прогресс, сохранить данные и перезапустить игру. Проверить точное восстановление ID, прогресса и завершения.
