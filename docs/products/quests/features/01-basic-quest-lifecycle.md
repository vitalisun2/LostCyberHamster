# 01 — Basic Quest Lifecycle

## Что это

Один квест получает прогресс и завершается при достижении цели.

## Задача

Создать минимальное ядро квеста, которое работает отдельно от сцены, UI и сохранения.

## Логика

1. Игра загружает одно определение квеста из контентных данных.
2. Определение содержит ID, ключ текста, тип условия `JumpOverObstacles` и цель `5`.
3. Для определения создаётся состояние с прогрессом `0`.
4. Входной прогресс увеличивает текущее значение.
5. Прогресс ограничивается целью.
6. Достижение цели завершает квест.
7. Завершённое состояние остаётся стабильным.

## Проверка

Передать прогресс ниже цели, ровно до цели и выше цели. Проверить значение и завершение на каждом шаге.
