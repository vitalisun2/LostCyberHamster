# 06 — Daily Quest Reward

## Что это

Завершённый ежедневный квест открывает одну ручную награду.

## Задача

Завершить продуктовый цикл квеста понятной выдачей игрового ресурса.

## Логика

1. Определение квеста хранит тип и размер награды.
2. Состояние квеста хранит отметку о получении.
3. Завершённая карточка показывает награду и кнопку получения.
4. Нажатие вызывает выдачу через `ResourceManager`.
5. Новый баланс переносится в `PlayerData`.
6. Получение награды сохраняется общим путём.
7. Карточка сразу показывает полученное состояние.
8. Повторный запрос сохраняет баланс без изменений.
9. Новая дата создаёт новое состояние награды вместе с квестом.

## Проверка

Завершить квест, получить награду и повторить запрос. Проверить один прирост ресурса, одинаковый баланс во всех хранилищах и восстановление после запуска игры.
