# 02 — Jump Over Progress Tracking

## Что это

Успешные перепрыгивания препятствий дают прогресс квесту после завершения уровня.

## Задача

Связать базовый квест с обычным игровым процессом.

## Логика

1. Старт уровня создаёт счётчик текущей попытки.
2. `OnObstacleJumpedOver` добавляет `1` в счётчик попытки.
3. Успешное завершение уровня передаёт накопленное значение квесту.
4. Квест обновляет прогресс и завершение через базовый жизненный цикл.
5. Новая попытка получает чистый счётчик.
6. Поражение или закрытие уровня сбрасывает незавершённую попытку.

## Проверка

Сделать несколько перепрыгиваний. Проверить перенос прогресса после победы и чистое состояние после незавершённой попытки.
