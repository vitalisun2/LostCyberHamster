# Quest Generation Rotation Concept

## Принятый концепт

### Daily

- На день выдаются три Daily-квеста (три разных квеста): простой, средний и сложный.
- Пул квестов и их уровни сложности берём из раздела 6 `research.md`.
- Выбранный набор сохраняется до следующего дня.
- Набор обновляется в полночь по текущему местному времени игрока.
- Одна и та же механика не повторяется два дня подряд, если в пуле есть подходящая замена.
- После получения наград всех трёх квестов игрок получает дополнительную общую награду.
- Через секунду после последней награды открывается модальное окно общего бонуса.

## Описание реализации

- `DailyQuestService` управляет текущим набором Daily и связывает его компоненты.
- `DailyQuestGenerator` выбирает по одному простому, среднему и сложному квесту с разными механиками. Завершённые квесты с незабранной наградой остаются. Вчерашние механики не повторяются при наличии замены.
- `DailyQuestScheduler` определяет первый запуск и наступление нового дня по местному времени.
- `DailyQuestSetState` хранит дату генерации, активные квесты, прошлый набор и состояние общей награды.
- `DailyCommonRewardDefinition` хранит тип и размер общей награды из `questData.json`.
- `QuestDefinition` хранит сложность Daily и стабильный ID его механики. Каждый вариант сложности остаётся обычным квестом из `questData.json`.
- Прогресс отдельных квестов остаётся в существующих `QuestState`.
- `QuestManager` использует `DailyQuestService`, получает активные квесты и управляет их жизненным циклом. `DailyQuestService` не зависит от `QuestManager`.
- `DailyQuestRewardModalController` показывает общий бонус и выдаёт его по кнопке. Экран квестов открывает модальное окно после обновления последней карточки.
