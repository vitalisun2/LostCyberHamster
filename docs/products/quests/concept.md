# Quests

## Этап 1 — Research

### Общий концепт

**Quests** — система игровых целей, которая добавляет игроку краткосрочные ежедневные задачи и долгосрочные ориентиры развития. Она разнообразит прохождение уровней, направляет игрока по контенту и выдаёт дополнительные награды за осмысленные игровые действия. Квесты активируются автоматически, выполняются фоном по событиям игры и данным прогресса, а их состояние сохраняется вместе с остальным состоянием игрока.

### Фичи продукта

1. **Один полностью работающий ежедневный квест** — в игре автоматически активируется и отображается один заранее заданный квест «перепрыгнуть 5 препятствий», который получает прогресс после успешного прохождения уровня, завершается при достижении цели, позволяет один раз забрать награду и восстанавливает своё состояние после перезапуска.

   **Проверка:** пройти уровень с нужным количеством прыжков, получить награду, проверить баланс, перезапустить игру и убедиться, что прогресс и получение награды не откатились.

2. **Автоматическая ежедневная выдача одного квеста из полного набора** — после смены локальной даты игра заменяет фиксированный квест автоматически выбранным заданием из всего согласованного набора, сохраняет этот выбор неизменным до следующего дня и позволяет выполнить любой выбранный тип через уже работающий цикл отображения, прогресса и получения награды.

   **Проверка:** входящий в фичу Editor-only выбор квеста по ID позволяет назначить и выполнить каждый тип в геймплее; тестовая смена даты подтверждает замену квеста и сохранение одного выбора внутри дня.

3. **Три ежедневных квеста разной сложности** — каждый день игра формирует и одновременно показывает простое, среднее и сложное задание без повторения одной механики, при этом каждый квест независимо обновляет прогресс, завершается, выдаёт награду и сохраняет своё состояние.

   **Проверка:** принудительно назначить известную тройку, выполнить каждое задание и проверить независимый прогресс и награды; генератор отдельно проверить на состав `Easy + Medium + Hard` и отсутствие повторения механики.

4. **Дополнительная награда за выполнение ежедневной тройки** — после завершения всех трёх ежедневных заданий игра открывает отдельную общую награду независимо от получения индивидуальных наград, позволяет забрать её только один раз и сохраняет это состояние после перезапуска.

   **Проверка:** завершить три задания, не забирать одну индивидуальную награду, получить общий бонус, перезапустить игру и убедиться, что повторное получение невозможно.

5. **Один сюжетный квест, выбранный по прогрессу игрока** — игра автоматически определяет актуальную часть суток, показывает цель «пройти все уровни текущей части суток», сразу учитывает ранее пройденные уровни, сохраняет конкретный объект цели до завершения и позволяет один раз получить награду.

   **Проверка:** использовать профиль, в котором до завершения части суток остался один уровень, пройти его, получить награду и после перезапуска проверить сохранение цели и невозможность повторной выдачи награды.

6. **Полный набор сюжетных квестов для разных этапов прогресса** — игра выбирает для одного сюжетного слота подходящую незавершённую цель из восьми согласованных шаблонов по уровням, частям суток, локациям, скинам и новым суперударам, сохраняет конкретный объект цели и не выдаёт завершённый квест повторно.

   **Проверка:** для каждого шаблона использовать подготовленный профиль с подходящим прогрессом, проверить выбранную цель на экране, выполнить её в игре, получить награду и убедиться, что цель больше не появляется.

7. **До трёх сюжетных квестов одновременно** — игра одновременно показывает от нуля до трёх разных актуальных целей, сохраняет уже назначенные цели неизменными и после получения награды за завершённый квест заполняет освободившееся место следующей подходящей целью.

   **Проверка:** использовать профили с нулём, одной, двумя и тремя доступными целями; завершить одну из них, получить награду и проверить заполнение освободившегося места без изменения остальных целей.
