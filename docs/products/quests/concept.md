# Quests

## Этап 1 — Research

### Общий концепт

**Quests** — ежедневные и сюжетные цели обычного геймплея. Система задаёт короткие задачи и долгие ориентиры, разнообразит уровни, награждает полезные действия. Игра загружает определения из контентного каталога, формирует цели, считает выполнение, хранит состояние в данных игрока, показывает прогресс и награды.

### Фичи продукта

1. **Quest Lifecycle** — активный квест получает прогресс, завершается по условию, один раз выдаёт награду. Ручное принятие отсутствует.
2. **Quest Catalog** — JSON-каталог неизменяемых определений. Каждое хранит стабильный ID, условие, цель, сложность, локализуемый текст, награду.
3. **Quest Progress Tracking** — игровые события, результат завершённого уровня и постоянный прогресс обновляют квесты фоном.
4. **Quest Player State** — общий `PlayerData` хранит назначение, прогресс, завершение, получение награды, дату ежедневного набора, стабильные сюжетные цели.
5. **Quest Rewards** — игрок вручную получает настроенную награду один раз. Ресурсная система синхронно обновляет runtime-баланс и сохранение.
6. **Quest UI** — отдельные списки ежедневных и сюжетных квестов: локализованное название, прогресс, награда, кнопка получения.
7. **Daily Quest Generation** — локальная дата получает три задания: простое, среднее, сложное. Механики в тройке разные.
8. **Daily Set Bonus** — завершение всей тройки открывает отдельную однократную награду. Доступность зависит только от завершения тройки.
9. **Story Quest Resolver** — прогресс игрока детерминированно даёт до трёх актуальных сюжетных целей. Каждая держит стабильный объект. Завершённые цели исключены из выбора.
