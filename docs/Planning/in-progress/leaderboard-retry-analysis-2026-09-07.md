# Лидерборд: повтор загрузки

Сценарий пользователя: кнопка «Повторить» сохраняет прежнее состояние экрана.
Ожидание: повтор читает выбранную таблицу и отображает ответ либо объясняет отказ.
Scope: runtime-диагностика лидерборда, без исправления логики.
Источники: docs/experience/error_diagnosis.md; .github/prompts/workflows/bug-regression-workflow.prompt.md.

Начальное состояние: Bootstrap.unity, Play Mode остановлен, automation idle. Unity 6000.2.6f2.
Чужое изменение: Assembly-CSharp.csproj. tool_usage.md изменён предыдущим диагностическим проходом.
Проверка: запуск Bootstrap; открытие лидерборда; повтор через зарегистрированный ClickEvent; чтение фактических guards и результата.
Гипотезы: недоступен coordinator; guard аккаунта/облака; исключение API; отбрасывание ответа; кеш/отрисовка.
