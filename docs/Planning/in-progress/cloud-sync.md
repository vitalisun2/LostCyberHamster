# Cloud Sync

- После полного локального commit тот же snapshot становится pending.
- Очередь хранит только последний snapshot для каждого `PlayerId` и переживает restart.
- Gameplay не ждёт сеть.
- Retry запускается при commit, старте, готовности account и reconnect. Повторные попытки используют backoff; одновременно выполняется один upload.
- Pending очищается только после подтверждения именно актуального snapshot.
- Конфликт определяется серверной revision, не локальным временем.
- Конфликт одного `PlayerId` отделён от входа в существующий аккаунт с другим `PlayerId`.
- Конкретная conflict policy пока не согласована.
