# будущие roof-сценарии

## Потом: roof дальше, но gap достижим

Нужна отдельная roof-стратегия для прыжка между крышами. Она должна смотреть состояние `RoofRun`, искать следующую roof-платформу на той же линии, проверять достижимый gap и планировать `RoofJump` / `SuperRoofJump` по runtime-механикам.

## Потом: gap слишком большой

Если следующая roof-платформа слишком далеко, planning не должен притворяться, что это пассивное продолжение. Возможный путь: добежать до конца текущей крыши, перейти в `RunFromRoof` / ground state, затем уже обычными ground-стратегиями выбрать `SwitchLane`, `JumpOnRoof` или другой подходящий маневр.

## Проверка

Сначала проверяем `01_New_York/Morning/test_jump_on_roof` с двумя `mediumNotAlive` подряд. Для gap-сценариев позже нужны отдельные test levels: достижимый roof gap и слишком большой roof gap.
