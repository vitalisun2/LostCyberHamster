# Bot strategy dead-end reasons — 2026-06-13

## Статус

- Тип: план/итог доработки.
- Scope: только dead-end участки уровня.
- Не scope: not-applicable strategies, missing travel/config, unsupported coverage, runtime cancel уже построенного plan.

## Цель

Если planner видит unresolved decision point, но ни одна применимая strategy не создала action, бот должен остановить validation run и вывести короткие причины от применимых strategies.

Причина выводится в формате:

```text
<StrategyName>: <короткая фраза>
```

## Контракт strategy result

Strategy возвращает один из вариантов:

- `FromAction` / `FromActions` — strategy применима и создала action.
- `DeadEnd(strategy, reason)` — strategy применима, но safety/window logic доказала непроходимость этого действия.
- `NotApplicable` — strategy не относится к текущей situation.
- `NoAction` — strategy применима, но отсутствие action не является level dead-end.

Dead-end report создается только при условиях:

```text
Actions.Count == 0
AND unresolved decision point still exists
AND DeadEndReasons.Count > 0
```

Если `DeadEndReasons.Count == 0`, это не level dead-end report.

## Классы причин

Оставляем только два смысловых класса:

1. Нет безопасного окна выполнения действия.
2. Небезопасное состояние после завершения действия.

Все конкретные фразы ниже являются уточнениями этих двух классов.

## Причины по strategy groups

### SwitchLane

- Нет безопасного окна для смены линии: до препятствия не остается положительного интервала запуска.
- Нет безопасного окна для смены линии: целевая линия перекрыта опасными препятствиями во всем допустимом интервале.
- Нет безопасного окна для смены линии: безопасный интервал слишком узкий для запуска действия.

### JumpOver / SuperJumpOver

- Нет безопасного окна для перепрыгивания: траектория прыжка не покрывает текущую цепочку препятствий.
- Safety margin не оставил безопасного окна для перепрыгивания.
- Нет безопасного окна для перепрыгивания: bigAlive требует дополнительный зазор, которого нет в этом участке.
- Нет безопасного окна для перепрыгивания: runtime-модель не подтверждает безопасный перелет выбранной цепочки.

### JumpOn / SuperJumpOn

- Нет безопасного окна для напрыгивания: target находится за правой границей безопасного окна запуска.
- Нет безопасного окна для напрыгивания: препятствие перед target закрывает траекторию.
- Нет безопасного окна для напрыгивания: до target остается опасный контакт с препятствием.
- Нет безопасного окна для напрыгивания: target не пересекается с допустимой траекторией прыжка.
- Safety margin не оставил безопасного окна для напрыгивания.
- Нет безопасного окна для напрыгивания: runtime-модель не подтверждает попадание в target.
- Небезопасное состояние после напрыгивания: перед target остается препятствие в зоне хомяка.
- Небезопасное состояние после напрыгивания: после возврата в Run хомяк пересекает следующее опасное препятствие.

### JumpOnRoof / SuperJumpOnRoof

- Нет безопасного окна для прыжка на крышу: окно посадки не пересекается с ограничениями траектории и контакта с цепочкой.
- Safety margin не оставил безопасного окна для прыжка на крышу.
- Нет безопасного окна для прыжка на крышу: входной край крыши занят опасным препятствием.
- Нет безопасного окна для прыжка на крышу: runtime-модель не подтверждает безопасную посадку на выбранную крышу.

### PassiveRoofExit

- Нет безопасного пассивного продолжения: на текущей крыше находится опасное препятствие.
- Нет безопасного окна для пассивного схода с крыши: интервал RunFromRoof пересекает дорожное опасное препятствие.

### JumpFromRoof / SuperJumpFromRoof

- Нет безопасного окна для прыжка с крыши: окно ухода с крыши не покрывает дорожную угрозу.
- Safety margin не оставил безопасного окна для прыжка с крыши.
- Нет безопасного окна для прыжка с крыши: bigAlive требует дополнительный зазор, которого нет в этом участке.
- Нет безопасного окна для прыжка с крыши: runtime-модель не подтверждает безопасный результат прыжка.

### JumpOnFromRoof / SuperJumpOnFromRoof

- Нет безопасного окна для напрыгивания с крыши: target находится за правой границей безопасного окна запуска.
- Нет безопасного окна для напрыгивания с крыши: окно попадания в target не пересекается с окном движения по текущей крыше.
- Нет безопасного окна для напрыгивания с крыши: препятствие перед target закрывает траекторию.
- Safety margin не оставил безопасного окна для напрыгивания с крыши.
- Нет безопасного окна для напрыгивания с крыши: runtime-модель не подтверждает попадание в target.
- Небезопасное состояние после напрыгивания с крыши: перед target остается препятствие в зоне хомяка.
- Небезопасное состояние после напрыгивания с крыши: после возврата в Run хомяк пересекает следующее опасное препятствие.

### JumpFromRoofOnRoof / SuperJumpFromRoofOnRoof

- Нет безопасного окна для прыжка на следующую крышу: окно движения по текущей крыше не пересекается с окном посадки на следующую крышу.
- Safety margin не оставил безопасного окна для прыжка на следующую крышу.
- Нет безопасного окна для прыжка на следующую крышу: bigAlive между крышами требует дополнительный зазор.
- Нет безопасного окна для прыжка на следующую крышу: runtime-модель не подтверждает посадку на выбранную крышу.

### RoofJumpOver / SuperRoofJumpOver

- Нет безопасного окна для прыжка над препятствием на крыше: roof-jump не покрывает текущую hazard-chain.
- Safety margin не оставил безопасного окна для прыжка над препятствием на крыше.
- Нет безопасного окна для прыжка над препятствием на крыше: runtime-модель не подтверждает безопасный прыжок.
- Небезопасное состояние после прыжка по крыше: после приземления нет безопасного продолжения RoofRun.

## Runtime behavior

`RuntimeBotController` при dead-end:

- пишет `[Bot DEAD_END]` в diagnostic log;
- пишет `[TEST RESULT] FAIL` в BOT/STAB channels;
- ставит игру на pause.

Пример:

```text
[Bot DEAD_END] reason=SpawnPattern depth=0 nextObstacleIndex=2 projection=12.59 causes=...
```
