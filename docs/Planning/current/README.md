# Current Planning Folder

Этот каталог зарезервирован только под активный план текущей задачи.

- Один файл плана на одну текущую задачу.
- После завершения задачи одноразовый план нужно удалить или перенести в более подходящее постоянное место, если он всё ещё ценен как спецификация.
- Этот `README.md` служит только placeholder-файлом, чтобы назначение каталога оставалось явным в git.
