# BotV3 Event-Driven Replanning

## Контекст

Текущий `BotOrchestrator` пересчитывает planner в каждом `Update()`, если бот активен и шаг не находится в `InProgress`.

Это расходится с целевой архитектурой проекта:

- planner должен запускаться только по runtime-триггерам;
- executor должен продолжать тикаться по кадрам, потому что он ждёт fire-distance и completion шага;
- изменение поведения бота недопустимо: меняется только момент пересчёта плана, а не семантика выбора действий.

## Цель итерации

Перевести `BotV3` на trigger-based replanning без изменения фактического поведения на тестовом уровне.

## Целевые инварианты

1. `BranchSelector.FindBestBranch()` не вызывается каждый кадр.
2. Пересчёт плана происходит только по триггерам:
   - первичная активация бота / сброс runtime-состояния;
   - изменение состава видимых объектов по набору `StableId`;
   - завершение или пропуск текущего шага executor'ом.
3. Если состав объектов изменился во время `InProgress`-шага, текущий шаг не прерывается.
   Пересчёт откладывается до завершения шага.
4. `StepExecutor` продолжает тикаться каждый кадр для:
   - ожидания fire-distance;
   - отправки runtime-команды;
   - отслеживания completion.
5. Публичное поведение бота на `test_level` остаётся прежним.

## Реализация

### Оркестратор

- Хранить флаг `replan requested`.
- Хранить последний набор видимых `StableId`.
- Каждый кадр собирать snapshot только для runtime-monitoring:
  - проверка изменения состава объектов;
  - передача live-контекста в planner только если реально нужен пересчёт.
- Если шаг `InProgress`, planner не вызывать.
- Если пришёл trigger и шага `InProgress` нет, выполнять один пересчёт и обновлять `CurrentPlan`.

### Executor

- `TryExecute()` должен явно сообщать оркестратору, завершился ли шаг в этом тике.
- Завершение включает:
  - обычный completion;
  - `too late` skip.

## Валидация

1. Компиляция изменённых C#-файлов.
2. Автопрогон `test_level` через automation bridge.
3. Чтение логов:
   - `STAB`
   - `BOT`
   - `ECO`
4. Сверка, что бот проходит уровень без новых падений и без очевидной смены паттерна поведения.
