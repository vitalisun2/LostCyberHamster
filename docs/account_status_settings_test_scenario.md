# Ручная проверка статуса аккаунта в Settings

> **Статус:** не выполнен пользователем (pending).
>
> Агент этот сценарий не запускает.

## Предусловия

- Запустить игру с любым текущим состоянием гостевого аккаунта.

## Шаги

1. Открыть `Settings`.
2. Проверить секцию `ACCOUNT` перед блоком версии.
3. Закрыть и повторно открыть `Settings`.

## Ожидаемый результат

- Отображается текущее состояние аккаунта: подготовка, гостевой аккаунт или ошибка.
- Для гостя показана одна строка `Гость, аккаунт не привязан`.
- Кнопка `ПРИВЯЗАТЬ АККАУНТ` видима, недоступна и не запускает авторизацию.
- Под кнопкой нет дополнительного текста или пустого блока.
- Повторное открытие показывает актуальное состояние; закрытие не меняет аккаунт.

## Cleanup / Reset

- Не требуется.

## Scope / не покрывает

- Не проверяются привязка, вход в существующий аккаунт, Retry и Cloud Save.
