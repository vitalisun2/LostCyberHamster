# 01. Успешный первый upload

Связано с [первым облачным снимком](../features/01-first-cloud-snapshot.md).

Статус: pending

## Предусловия

- Гость A не привязан, а для его будущего аккаунта нет облачного снимка.
- У гостя A записаны контрольные значения прогресса, валюты и скинов.

## Шаги

1. Явно привязать гостя A к аккаунту при доступной сети.
2. Во время отправки продолжить обычное взаимодействие с игрой.
3. Дождаться подтверждения сохранения и сверить сохранённый облачный снимок с записанными значениями.

## Ожидаемый результат и логи

Игра не блокируется; в облаке для текущего UGS `PlayerId` появляется один целый снимок гостя A. UI показывает `Saved`, а наблюдаемое состояние/лог категории cloud save подтверждает успешную запись целого снимка для этого `PlayerId`.

## Cleanup

Удалить тестовый облачный снимок и отвязать тестовый аккаунт.

## Scope

Проверяется только успешная первая отправка после привязки, без восстановления на другом устройстве.
