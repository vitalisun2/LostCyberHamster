# 06. Durable pending сохраняется офлайн

Связано с [офлайн-изменениями](../features/04-offline-pending-reconnect.md).

Статус: pending

## Предусловия

- Привязанный аккаунт синхронизирован и находится в состоянии `Saved`.
- Известны исходные контрольные значения.

## Шаги

1. Отключить сеть.
2. Выполнить поддерживаемую контрольную точку и записать новые значения.
3. Убедиться, что UI показывает `Offline`, затем закрыть приложение.
4. Запустить приложение при всё ещё отключённой сети и сверить значения и статус.

## Ожидаемый результат и логи

Новый целый снимок сохранён локально и остаётся pending после перезапуска; UI снова показывает `Offline`. Наблюдаемое состояние/лог категории pending sync подтверждает наличие несинхронизированного снимка для исходного UGS `PlayerId`.

## Cleanup

Вернуть сеть и дождаться завершения pending-синхронизации.

## Scope

Проверяется сохранность одного актуального pending-снимка, без конфликта другого устройства.
