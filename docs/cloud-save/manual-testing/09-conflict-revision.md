# 09. Конфликт решается по revision

Связано с [безопасным выбором снимка](../features/05-conflict-safe-multi-device-sync.md).

Статус: pending

## Предусловия

- Для одного UGS `PlayerId` локальный снимок L и облачный снимок C имеют одинаковый progression rank.
- У L выше revision, а у C позднее server time; выполняется обычная синхронизация.

## Шаги

1. Записать контрольные значения L и C.
2. Запустить обычную синхронизацию аккаунта.
3. Дождаться разрешения конфликта и `Saved`.
4. Сверить runtime, локальный и облачный снимки.

## Ожидаемый результат и логи

Целиком побеждает L с большей revision; позднее server time снимка C не меняет выбор. Наблюдаемое состояние/лог категории conflict resolution указывает revision как решающий критерий.

## Cleanup

Восстановить исходный облачный снимок тестового аккаунта.

## Scope

Проверяется второй критерий после равного progression rank.
