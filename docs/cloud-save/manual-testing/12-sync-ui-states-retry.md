# 12. UI-статусы и ручной retry

Связано со [статусом синхронизации](../features/06-sync-status-manual-retry.md).

Статус: pending

## Предусловия

- Привязанный аккаунт полностью синхронизирован.
- Тестовая среда позволяет замедлить upload и отдельно вызвать одну сетевую и одну несетевую ошибку.

## Шаги

1. Убедиться, что UI показывает `Saved`.
2. Замедлить upload, выполнить контрольную точку и проверить `Syncing`, продолжая взаимодействовать с игрой.
3. Отключить сеть до подтверждения и проверить `Offline`.
4. Вернуть сеть, подготовить несетевой отказ и нажать retry: проверить переход `Syncing` → `Error`.
5. Убрать отказ и снова нажать retry: проверить переход `Syncing` → `Saved`.

## Ожидаемый результат и логи

UI последовательно и без блокировки показывает `Saved`, `Syncing`, `Offline`, `Syncing`, `Error`, `Syncing`, `Saved`. Неудачи не удаляют локальный pending-снимок; финальный retry отправляет его целиком. Наблюдаемое состояние/лог категорий статуса и cloud retry отражает попытки и их фактические исходы без ложного `Saved`.

## Cleanup

Убрать эмуляцию задержки и ошибок, восстановить исходный тестовый снимок.

## Scope

Проверяется одна последовательность статусов и ручного retry; визуальный дизайн индикатора не оценивается.
