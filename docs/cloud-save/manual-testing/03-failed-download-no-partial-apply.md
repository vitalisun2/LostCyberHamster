# 03. Ошибка download не применяет снимок частично

Связано с [восстановлением существующего аккаунта](../features/02-restore-existing-account-progress.md).

Статус: pending

## Предусловия

- На устройстве есть целый локальный снимок B с записанными контрольными значениями.
- Аккаунт A имеет отличающийся облачный снимок; тестовая среда может оборвать или отклонить его download до успешного завершения.

## Шаги

1. Явно начать вход в существующий аккаунт A.
2. Во время cloud download вызвать подготовленный отказ.
3. После сообщения об ошибке сверить все runtime- и локальные значения со снимком B.
4. Перезапустить игру без успешного повтора download и снова сверить значения.

## Ожидаемый результат и логи

Текущий локальный снимок B целиком остаётся активным; ни одно поле снимка A не применяется. Наблюдаемое состояние/лог категории восстановления фиксирует неуспешный download и отсутствие применения cloud snapshot.

## Cleanup

Отключить тестовый отказ и очистить локальные тестовые данные.

## Scope

Проверяется атомарность при ошибке download, но не последующий успешный retry.
