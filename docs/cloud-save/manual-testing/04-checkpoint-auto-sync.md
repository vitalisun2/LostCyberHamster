# 04. Автосинхронизация контрольной точки

Связано с [автоматической синхронизацией](../features/03-automatic-checkpoint-sync.md).

Статус: pending

## Предусловия

- Привязанный аккаунт находится в состоянии `Saved` при доступной сети.
- Известны исходные значения валюты и набора скинов; доступна покупка тестового скина как контрольная точка.

## Шаги

1. Купить тестовый скин.
2. Сразу после покупки перейти в другой доступный экран или продолжить управление.
3. Дождаться завершения автоматической синхронизации.
4. Сверить локальный и облачный целые снимки с результатом покупки.

## Ожидаемый результат и логи

Покупка сразу сохранена локально, игра не ждёт облако, затем UI возвращается в `Saved`. Облачный снимок целиком содержит купленный скин и актуальный остаток валюты; наблюдаемое состояние/лог категории checkpoint sync показывает старт и успешное подтверждение неблокирующей записи.

## Cleanup

Восстановить исходный тестовый снимок аккаунта.

## Scope

Проверяется одна поддерживаемая контрольная точка; полный перечень checkpoint-событий не покрывается.
