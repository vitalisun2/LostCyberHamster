# 06. Статус синхронизации и ручной повтор

## Что и зачем

Игра показывает понятный статус облачного сохранения — `Saved`, `Syncing`, `Offline` или `Error` — и позволяет неблокирующе повторить неудачную синхронизацию. Игрок понимает, сохранён ли прогресс в облаке, не прерывая игру.

- [05. Безопасный выбор снимка при игре на нескольких устройствах](05-conflict-safe-multi-device-sync.md).

## Продуктовый алгоритм

1. `Saved`: актуальный локальный снимок подтверждён облаком, ожидающих изменений нет.
2. `Syncing`: выполняется неблокирующая попытка загрузки, восстановления или разрешения конфликта.
3. `Offline`: есть несинхронизированный локальный снимок, но облако недоступно из-за отсутствия подключения.
4. `Error`: последняя попытка завершилась ошибкой, не объясняемой текущим отсутствием подключения.
5. Ручной повтор запускает неблокирующую синхронизацию актуального целого снимка.
6. Результат повтора переводит статус в `Saved`, `Offline` или `Error` по фактическому исходу.

## Критерии приёмки

- В каждый момент показывается один из четырёх статусов: `Saved`, `Syncing`, `Offline`, `Error`.
- `Saved` не показывается, пока актуальный снимок ожидает отправки или подтверждения.
- Ручной повтор доступен для `Offline` и `Error` и не блокирует игровой процесс.
- Повтор использует правила целого снимка и безопасного разрешения конфликта.
- Ошибка повтора не удаляет локальный прогресс и не сбрасывает durable-признак ожидания.

## Граничные случаи

- Пользователь нажимает повтор несколько раз: параллельные попытки не должны приводить к применению старого снимка поверх нового.
- Сеть пропадает во время `Syncing`: статус переходит в `Offline`, если актуальный снимок ещё не подтверждён.
- Новая контрольная точка возникает во время `Syncing`: статус остаётся несохранённым в облаке до подтверждения самого актуального снимка.
- Нет ожидающих изменений, но чтение облака завершилось ошибкой: статус отражает ошибку операции, не заявляя ложный `Saved`.

## Вне рамок

- Подробный журнал синхронизаций для пользователя.
- Ручной выбор локальной или облачной версии.
- Блокирующие модальные окна для обычной синхронизации.
- Автоматическая поддержка через отправку диагностик.
