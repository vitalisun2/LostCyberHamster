# Cloud Save

## Зафиксированные продуктовые решения

- Облако хранит один атомарный снимок всей игры для текущего UGS `PlayerId`.
- При привязке гостевого аккаунта первая загрузка отправляет в облако текущий гостевой прогресс.
- При явном входе в существующий аккаунт облачный снимок полностью заменяет текущий гостевой прогресс; гостевой прогресс не сохраняется.
- Локальное сохранение выполняется сразу, облачная синхронизация — неблокирующе.
- До реализации восстановления существующего аккаунта кросс-девайсное продолжение игры не обещается.
- Несинхронизированный локальный снимок durable-помечается и повторно отправляется после восстановления подключения.
- При обычном конфликте одного аккаунта выбирается один целый снимок по порядку: ранг прогресса, ревизия, серверное время; при явном входе в существующий аккаунт всегда побеждает облако.
- Экономика никогда не объединяется по отдельным полям.
- UI показывает `Saved`, `Syncing`, `Offline` или `Error`; ручной повтор остаётся неблокирующим.

## Текущие разрывы

- Облачная загрузка в bootstrap может начаться раньше завершения неблокирующего запуска `AccountService`.
- Legacy-выбор версии опирается на клиентский `LastSaveDate`.
- Сейчас в облако отправляется только покупка скина.
- Привязка и вход не интегрированы с `GameDataManager`; после смены `PlayerId` в runtime остаётся гостевое состояние.
