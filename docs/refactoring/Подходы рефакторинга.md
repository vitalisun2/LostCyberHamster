# Подходы рефакторинга

## 1. Параллельная миграция с постепенным замещением

Новую модель вводим рядом со старой, не ломая рабочий код.

Меняем только те части, где реально меняется контракт или поведение. Новый путь подключаем минимальным рабочим вертикальным срезом, проверяем его, затем поэтапно переносим остальные части.

Когда новый путь полностью заменяет старый, удаляем старую логику, временные переключатели, адаптеры и лишние обертки.
