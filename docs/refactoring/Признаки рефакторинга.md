# Признаки рефакторинга

Этот документ предназначен для накопления практических признаков, по которым можно быстро увидеть слабые места класса или метода: технический долг, лишнюю сложность, неудачные проверки, неочевидную структуру, ухудшение читаемости, избыточные зависимости, сомнительные оптимизации и другие сигналы к улучшению. Его цель — дать единый список ориентиров для оценки качества кода и помочь точнее формулировать, что именно в текущей реализации стоит упростить, разделить, переименовать, защитить проверками или перестроить.
