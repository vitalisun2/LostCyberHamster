# Return existing account

Статус: не выполнен пользователем (pending)

Предусловия: приложение запущено под гостем; выбранный Unity Player Account уже связан с другим UGS-профилем.

Шаги:

1. Открыть Settings и нажать «ПРИВЯЗАТЬ АККАУНТ».
2. Завершить вход в уже связанный Unity Player Account.
3. Проверить inline-предупреждение о существующем профиле и отсутствии переноса/объединения прогресса гостя.
4. Закрыть Settings, снова открыть и убедиться, что предложение входа сброшено, а текущий гость сохранён.
5. Повторить шаги 1–2 и нажать «ВОЙТИ».

Ожидаемый результат и логи: во время переключения кнопка недоступна и показан статус входа; после успеха отображается привязанный аккаунт с другим PlayerId. При безопасно восстановленной ошибке доступна повторная попытка; при неподтверждённом восстановлении отображается ошибка аккаунта.

Cleanup/reset: использовать штатный dev-only full reset тестового аккаунта.

Scope / не покрывает: перенос или объединение прогресса, Cloud Save и удаление аккаунтов.
