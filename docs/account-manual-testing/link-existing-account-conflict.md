# Конфликт с существующим аккаунтом

**Статус:** не выполнен пользователем (pending).

## Предусловия

- Текущее состояние аккаунта — `Guest`.
- Выбранный Unity Player Account уже привязан к другому UGS Player ID.
- Текущий гостевой UGS Player ID зафиксирован для сравнения.

## Шаги

1. Открыть `Settings` и нажать `ПРИВЯЗАТЬ АККАУНТ`.
2. Выполнить вход в уже привязанный Unity Player Account.
3. Сравнить текущий UGS Player ID с исходным.

## Ожидаемый результат

- Показано `Этот аккаунт уже привязан. Используйте вход в существующий аккаунт.`
- Текущий аккаунт остаётся гостевым, его UGS Player ID не меняется.
- Кнопка `ПРИВЯЗАТЬ АККАУНТ` снова доступна.
