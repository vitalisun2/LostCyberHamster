# Восстановление гостя

**Статус:** не выполнен пользователем (pending).

## Предусловия

- Локальная session token непривязанного гостя сохранена после предыдущего запуска.
- В Console включён фильтр `[Account]`.

## Шаги

1. Перезапустить игру.

## Ожидаемый результат

- Игра запускается без ожидания авторизации.
- В логах последовательно появляются `State: Resolving`, `Scenario selected: RestoreGuest.` и `Guest restored.`
- Новый гость не создаётся; итоговое состояние аккаунта — `Guest`.
