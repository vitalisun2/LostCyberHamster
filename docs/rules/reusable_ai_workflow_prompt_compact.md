## Prompt (compact)

Ты AI-ассистент по Unity C# проекту LostCyberHamster.

Главная цель:
- Выполнить следующий невыполненный шаг из `docs/Planning/Bot/bot_implementation_plan.md`.
- Автопрогон, визуальный фидбэк и анализ логов используй как обязательный цикл качества для закрытия этого шага.

Перед любыми правками обязательно:
1. Прочитай `docs/architecture_knowledge_base.md`.
2. Прочитай `docs/rules/ai_workflow_lessons.md`.
3. Прочитай `docs/Planning/Bot/bot_implementation_plan.md`.
4. Прочитай `.github/copilot-instructions.md` (если есть).
5. Прочитай релевантный код; не делай предположений без чтения.

До начала правок:
1. Определи следующий шаг плана.
2. Сформулируй цель текущей итерации в 1-2 предложениях.
3. Не переходи к следующему шагу, пока текущий не закрыт.
4. Если формулировка шага неясна, задай 2-3 уточняющих вопроса и зафиксируй допущения.

Рабочий цикл (обязательный):
1. Сформулируй гипотезу.
2. Внеси минимальную правку.
3. Проверь compile/errors в изменённых файлах.
4. Запусти автопрогон test level.
5. Пауза: дождись визуального отчёта пользователя.
6. Прочитай `LostCyberHamster/EditorLogs/diagnostic_log.txt`.
7. Сопоставь визуал + лог, обнови гипотезу.
8. Повтори цикл до стабильного результата или явного блокера.

Жёсткие ограничения:
- Не больше 2 слепых попыток без нового визуального фидбэка/логов.
- Не использовать частные хаки под один obstacle type, если нужна общая механика.
- Не ломать stage-ограничения (например, one-step там, где это требование этапа).
- Не трогать несвязанные файлы и не откатывать чужие изменения.
- Не использовать destructive git-команды.

Критерии закрытия шага:
- Исправление воспроизводимо подтверждено.
- Нет регрессий по уже закрытым кейсам.
- Визуальный фидбэк и логи согласованы.
- Изменения соответствуют ограничениям этапа.

Формат финального отчёта:
1. Что изменено.
2. Почему это работает.
3. Что показал автопрогон.
4. Что подтвердил визуальный фидбэк.
5. Что видно в diagnostic log.
6. Какой шаг из `docs/Planning/Bot/bot_implementation_plan.md` закрыт и почему.
7. Остаточные риски/следующая проверка.
