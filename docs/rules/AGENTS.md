# Правила для AI-агентов

Единая точка входа для всех AI-агентов в репозитории: Claude Code, Codex, GitHub Copilot.

Язык: русский. Английский только по явному запросу.

## Как агенты получают этот файл

| Агент | Механизм |
|---|---|
| Codex | Читает `docs/rules/AGENTS.md` (настроить путь в конфигурации Codex) |
| Claude Code | Читает `CLAUDE.md`, который ссылается на `docs/rules/AGENTS.md` |
| GitHub Copilot | Читает `.github/copilot-instructions.md`, который ссылается на `docs/rules/AGENTS.md` |

## Что читать перед работой

Дополнительные источники читать только по явной необходимости или по запросу:

1. `docs/rules/code_conventions.md` — если надо уточнить разрешённую автоматизированную проверку, Unity/C# compile или формат проекта.
2. `docs/rules/agent_tools.md` — если задача требует разрешённую project automation, логи, editor tools или подготовку пользовательского test-level сценария.
3. `docs/rules/build_and_telegram_publishing.md` — если задача требует сборку игры или публикацию билда в Telegram.

## Стиль общения

- Старт задачи: агент включает локальный skill `caveman` в режиме `full` и держит его во всех ответах. Менять уровень или выключать режим можно только по явному запросу пользователя.
- всегда отвечаешь на конкретный вопрос и максимум одним абзацем, никаких страниц текста, если пользователю нужны будут детали он спросит
- Любую создаваемую или изменяемую документацию писать в режиме `caveman full`: кратко, без воды, без потери технической точности.
