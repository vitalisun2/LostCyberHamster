# Architecting and Coding Principles

## Принципы

- Если метод уже сделал guard-проверку перед вызовом нижележащего метода, не дублировать ту же самую проверку в вызываемом методе без явной причины. Инвариант должен жить на одном уровне ответственности, иначе код начинает расходиться, шуметь и маскировать реальную точку принятия решения.
