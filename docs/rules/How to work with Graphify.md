# How to work with Graphify

Graphify строит карту архитектуры проекта: связывает файлы, типы, методы, вызовы, наследование и другие зависимости. Используй карту, чтобы быстро исследовать путь между подсистемами и сократить объём чтения исходников.

## Когда использовать

Graphify полезен для:

- архитектуры нескольких подсистем;
- зависимостей между тремя и более файлами;
- неизвестного пути данных или вызовов;
- связей между игровым кодом, сервисами и инструментами тестирования.

Для известного символа, одной-двух файлов, локальной правки, теста или runtime-проверки используй `rg` и читай исходники напрямую.

## Рабочий процесс

1. Сформулируй конкретный вопрос и определи scope.
2. Проверь наличие `graphify-out/graph.json`.
3. Если исходники менялись после построения карты, обнови граф:

   ```powershell
   graphify update .
   ```

   Инкрементальный update находит новые, изменённые и удалённые файлы, переизвлекает изменённые части, обновляет связи, отчёт и визуализацию.
4. Выполни scoped `query`, `path` или `explain`.
5. Проверь найденные связи по актуальному исходному коду.
6. В ответе укажи `source_location`, если вывод опирается на файл или строку.

Graphify даёт навигацию и контекст. Фактическое поведение подтверждается исходным кодом, тестами и runtime-доказательствами.

## Основные команды

Архитектурный вопрос:

```powershell
graphify query "Как экран X получает данные из сервиса Y?"
```

Точный обход связей через DFS с ограничением ответа:

```powershell
graphify query "Как награда проходит от победы до сохранения?" --dfs --budget 1500
```

Кратчайшая связь между сущностями:

```powershell
graphify path "PlayerExperienceService" "PlayerData"
```

Объяснение узла:

```powershell
graphify explain "GameEventsManager"
```

## Построение и кластеризация

Полная пересборка нужна при первичной настройке или восстановлении карты:

```powershell
graphify extract . --code-only
```

Пересчёт сообществ на существующем графе:

```powershell
graphify cluster-only .
```

Для изменений только в коде используется AST-извлечение. Документы, изображения и другие semantic-файлы могут запускать semantic extraction и отдельную обработку.

## Сгенерированные файлы

Graphify сохраняет карту и служебные данные в `graphify-out/`:

- `graph.json` — данные графа;
- `GRAPH_REPORT.md` — отчёт и анализ;
- `graph.html` — интерактивная визуализация;
- `manifest.json` — база для инкрементальных обновлений;
- кэш и промежуточные файлы извлечения.

`graphify-out/` — каталог генерируемых данных, исключённый из commit/push. Его dirty-состояние после `update` или hook ожидаемо.
