# Progress System Baseline\n\n- Level completion unlocks the next level sequentially (same part/day, then next part, then next location).\n- Stars earned per level are clamped to 0..3 and persisted via LevelProgressEntry.ApplyStars.\n- Completing a level immediately unlocks the next level entry regardless of star count.\n- Stars required for the next location = (max stars of current unlocked location) - star offset (2).\n- OpenedLocations returns contiguous locations starting from index 0 where at least one level entry has IsUnlocked.\n
\n## Test ideas\n- Unit: DefaultUnlockPolicy.CanUnlockNextLocation returns false when deficit exists.\n- Unit: ProgressService.HandleLevelCompleted keeps next location locked until required stars collected.\n- Integration: Simulate completion of sequential levels and verify snapshot updates accordingly.\n
\n## Manual verification checklist\n- Reset progress via ProgressService.ResetProgress() in debug tools before test run.\n- Complete Morning level with varying star counts; confirm next level unlocks immediately.\n- Attempt to unlock next location without enough stars; ensure it stays locked.\n- Earn additional stars to meet requirement; verify location unlocks and UI updates.\n
