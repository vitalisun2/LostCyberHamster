# Манифест проверки

Манифест хранится в `Version N/Working Files/`. Пути к изображениям указывай относительно JSON-файла или абсолютными. Координаты полигонов и позиции спрайтов относятся к исходному кадру. Размер `edited_mask` равен исходному кадру; ненулевые пиксели показывают все области, где разрешено менять фон.

```json
{
  "qa_contract_version": 2,
  "source": "source.png",
  "empty_background": "../Backgrounds/empty_2000.png",
  "unpainted_empty_background": "empty_before_paint.png",
  "required_cutout_regions": [
    {"id": "lower_annex", "polygon": [[1300, 690], [1390, 690], [1390, 710], [1300, 710]]}
  ],
  "movement_preview": "QA/moved_preview.png",
  "required_preview_opaque_regions": [
    {"id": "courtyard_foundation", "polygon": [[1300, 650], [1390, 650], [1390, 660], [1300, 660]]}
  ],
  "extended_background": "../Backgrounds/empty_3000.png",
  "edited_mask": "QA/allowed_background_changes.png",
  "required_paving_mask": "QA/required_paving_mask.png",
  "preserved_road_mask": "QA/preserved_road_mask.png",
  "sidewalk_rise": {
    "top_y": 640,
    "original_top_y": 718,
    "building_heights": [150, 160, 170],
    "max_fraction_of_mean_height": 0.5
  },
  "height_midpoint": {
    "house_ids": ["courtyard_complex"],
    "paving_intervals_x": [[0, 2000]]
  },
  "extension": {"split_x": 1250, "insert_width": 1000},
  "sprites": [
    {
      "id": "courtyard_complex",
      "file": "../Sprites/courtyard_complex.png",
      "source_position": [1124, 583],
      "required_anchor_points": [[1150, 620], [1280, 640], [1370, 650]],
      "forbidden_polygons": [
        [[1275, 691], [1400, 691], [1400, 711], [1275, 711]]
      ],
      "repair_polygons": []
    }
  ]
}
```

`forbidden_polygons` помечают известные поверхности фона внутри прямоугольника спрайта: открытый двор, дорогу, тротуар, предмет, оставленный на фоне. Скрипт считает ненулевую альфу там ошибкой. Полигон можно задать и за границами спрайта; учитывается пересечение.

`repair_polygons` помечают пиксели фасада, восстановленные после перекрытия другим предметом. В остальных видимых пикселях спрайт должен совпадать с RGBA исходника. Если восстановлений нет, укажи пустой список. Для каждой сложной группы задай как минимум один участок с ожидаемой прозрачностью, а после работы скрипта всё равно осмотри контур целиком.

`required_anchor_points` закрепляют несколько видимых частей одного архитектурного комплекса за одним спрайтом: например, левое крыло, центральный фасад и правое крыло площади. `required_cutout_regions` независимо отмечают нижние магазины и пристройки, которые должны исчезнуть из `unpainted_empty_background` до дорисовки. `required_preview_opaque_regions` задают места под передвинутыми основаниями, где `movement_preview` должен быть непрозрачным. Эти области размечай по исходнику и пробной композиции отдельно от масок нарезки.

При расширении тротуара вверх укажи `required_paving_mask`: все её пиксели должны быть непрозрачными в пустом фоне. `preserved_road_mask` помечает дорогу, бордюры, повороты и выходы; их RGBA должен совпасть с исходником. В `sidewalk_rise` запиши прежнюю и новую верхние кромки и видимые высоты всех движимых домов без прозрачных полей. Половина средней высоты — дополнительный ориентир для **добавленного подъёма**.

Для новых сцен укажи `qa_contract_version: 2`: при подъёме тротуара манифест обязан содержать `height_midpoint`. Старые манифесты без версии продолжают проверяться по прежнему контракту.

`height_midpoint.house_ids` перечисляет каждый дом или цельный архитектурный комплекс. Скрипт берёт крайние непрозрачные y этих спрайтов в исходных координатах и вычисляет середину. `paving_intervals_x` задаёт нужную ширину тротуара полуоткрытыми интервалами `[x0, x1)`; несколько интервалов позволяют обойти сохранённый дорожный выход. Скрипт находит верхнюю кромку по `required_paving_mask` в каждом столбце. Самый низкий участок кромки должен достичь середины, а линия середины должна быть заполнена по всей указанной ширине. При конфликте с ориентиром половины средней высоты правило середины имеет приоритет. Результат и размеченное превью сохраняются в QA.

Скрипт сохраняет `qa-report.json`, контактный лист, крупный обзор каждого спрайта рядом с его фрагментом исходника, маску правок фона и карту разницы обратной сборки. Несовпадение проверяемых инвариантов даёт ненулевой код выхода.

Запуск из каталога скилла:

```powershell
python scripts/review_scene.py --manifest <путь-к-review-manifest.json> --out <папка-QA>
```

Нужны Python 3, Pillow и NumPy. После автоматической проверки сохрани три наглядных сравнения в исходных координатах: прежний и новый пустой фон, пробную сборку со сдвигом домов вверх, исходные и готовые дорожные выходы с бордюрами. Просмотри их в масштабе 100% и выше. Приложи к итогу высоту общей середины и диапазон верхней кромки мощения. Любое расхождение с требованиями исправь до выдачи результата.
