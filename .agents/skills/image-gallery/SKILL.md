# Галерея изображений

Использовать готовый сборщик и шаблон. Агент выбирает изображения, порядок, группы и подписи. Python 3, стандартная библиотека. Unity и приложение-источник для сборки не требуются.

## Вход

Сборщик принимает один `--src` и сам определяет источник:

- JSON-манифест галереи.
- Папку результата `unity-ui-capture` с `capture-manifest.json`.
- Обычную папку с изображениями. Каждая верхнеуровневая директория становится отдельным `case`; изображения в корне попадают в отдельный раздел.

Для JSON сохранить понятные пользователю группы (`cases`) и изображения/состояния (`states`). Для user flow сохранить порядок. Пути `file` — абсолютные или относительно JSON.

```json
{
  "title": "Варианты интерфейса",
  "description": "Концепты и состояния",
  "cases": [{
    "id": "profile",
    "title": "Профиль",
    "states": [{
      "id": "empty",
      "title": "Пустое состояние",
      "file": "images/profile.png",
      "note": "Новый пользователь"
    }]
  }]
}
```

`id`: латинские строчные буквы, цифры, дефисы; уникален внутри родителя. Форматы браузера: PNG, JPEG, WebP, GIF, SVG, AVIF, BMP, ICO. Для PSD, HEIC и других исходников подготовить браузерные превью доступным конвертером, оригинал сохранить отдельно.

Дополнительно: `case.source` — источник; `state.method` — способ подготовки; `width`/`height` — известные размеры. Для отсутствующего кадра: `captured: false`, `error` с причиной, без `file`. Такие позиции остаются в галерее. `complete: false` и `status` позволяют источнику явно передать незавершённость или предупреждение; сборщик не оценивает прохождение сценария.

## Сборка и выдача

Путь к скрипту брать от расположения этого скилла:

```powershell
python <image-gallery>/scripts/gallery.py build --src <источник>
python <image-gallery>/scripts/gallery.py build --src <источник> --mode bundle --out <папка-галереи>
python <image-gallery>/scripts/gallery.py serve --out <папка-галереи> --port 8767
```

По умолчанию сборщик создаёт sidecar-папку `<источник>_gallery` рядом с источником и работает в режиме `linked`: viewer хранится отдельно, изображения читаются по относительным путям без копирования. Режим `bundle` копирует изображения без обработки в `images/`, сохраняет SHA256, `manifest.json`, `index.html`; такую папку можно целиком перенести. `--manifest` сохраняется как legacy alias для JSON-источника.

Повторная сборка допустима. HTML работает напрямую, сервер нужен только для браузерного просмотра. `serve` сам подбирает общий корень, чтобы linked-галерея открывала соседние папки с PNG. На Windows фоновый сервер запускать скрытым.

Открыть готовую страницу, проверить загрузку изображений, подписи и увеличение. Дать ссылку и число групп/изображений. Анализ дизайна выполнять по отдельному запросу. Для получения экранов Unity использовать соседний `unity-ui-capture`; он вызывает этот сборщик только с флагом `--gallery`.
